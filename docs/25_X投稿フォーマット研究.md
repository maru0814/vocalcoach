# X（旧Twitter）で伸びる投稿フォーマット研究 — ソラ先生 新規アカウント運用

> マーケター作成。新規アカウント（フォロワー0）から、声タイプ診断のシェアループに点火するための「投稿の型」研究。
> 2026年のXアルゴリズム実態を踏まえた**実戦テンプレ集**。誇大表現はしない（型は“打率”を上げるもので、バズは確約しない）。

## 0. 結論（先に要点）
1. **リンクは本文に入れない。リプ（返信）に貼る。** 本文に外部リンクがあるとリーチが50〜90%減。**新規・無認証アカウントは本文リンクで“ほぼ表示されない”**。→ 本文はフック＋画像、リンクは1つ目の自己リプへ。
2. **最強シグナルは「リプ（会話）」。** いいねの約150倍の価値。**問いかけ・共感で“返信したくなる”投稿**を作る。
3. **勝負は投稿後30〜60分の初速。** 出した直後に自分でもリプ欄で会話し、初動を作る。
4. **画像2〜4枚**で滞在時間（dwell time）が伸びる。→ 診断の**8キャラ画像**や**結果カード**が武器。
5. **日本は「共感（あるある）」がフォローに直結。** 情報より“自分ごと”。
6. 投稿時間の目安：**朝7–8 / 昼12 / 夜19–23**。特に「**木曜夜×共感**」「**日曜午後×ビジュアル**」。

## 1. 伸びる「型」7つ（ソラ先生テンプレ付き）

### 型①：共感あるある（フォロワー獲得の主力／リンクなし）
人は“情報”より“自分のこと”に反応する。リプ・引用で自分の体験を語らせる。
```
カラオケのサビ、原曲キーで最後まで余裕な人、
ほんと何者なんだ……🎤

こっちは2番のサビで毎回 酸欠なんだが。
```
> CTA不要。共感だけ。リプ欄に「わかる」が集まると一気に伸びる。

### 型②：自己分類フック（診断＝MBTIの構造／画像2–4枚＋リンクはリプ）
人は「自分を分類する」のが大好き。診断の核。
```
あなたの歌声、実はこの8タイプのどれかです。

🔥Rock / 🎙Groovy / 🌤Pop / 🌒Mysterious
💎Crystal / 🎭Dramatic / 🍃Whisper / 🌙Moody

直感でどれっぽい？（答え合わせは下に🔽）
```
（画像：8キャラのギャラリー）→ **1つ目のリプに診断リンク**。

### 型③：逆張り／常識否定（保存・引用されやすい）
```
「高い声は“喉を開けば”出る」
↑これ、半分ウソです。

実際は “閉じる場所” と “息の支え” の問題。
喉を開くほど スカスカに抜けることもある。
```

### 型④：番号付きTips（ブックマーク＝滞在シグナル）
```
音痴を直す前に “やめるべき” 3つの癖👇

①いきなり大声で合わせにいく
②原曲を聴かずに歌う
③外した音を放置して次へ進む

直すより「やめる」が先。
```

### 型⑤：Before→After（変化を見せる）
```
サビで毎回 息が切れてた人が、
1日30秒の“ある練習”を5日続けたら——

ロングトーンが2倍伸びた。

やったのは「リップロール」だけ。
```

### 型⑥：問いかけ（リプを直接取りにいく）
```
歌で一番 直したいの、どれ？

① 音程
② リズム
③ 高音
④ 声量・通り

番号でこっそり教えて🙌（全部 直し方あるよ）
```

### 型⑦：個人開発スレッド（“人”を見せる＝新規でも伸びる）
```
個人で「AIボイストレーナー」作ってます🎤

歌を録音すると、AIが
・音程／リズム／表現を解析
・今日直す所
・声タイプ（8種）診断
まで返す。

今日やったこと→🧵
```
> スレッドは滞在時間が伸びる。最後のツリーにリンク。

## 2. 1行目（フック）の作り方
**最初の1行で読むか決まる。** 効く型：
- **断定＋意外性**：「音程が合わない原因、9割は“耳”じゃない。」
- **数字**：「高音が出ない人の8割がやってる、たった1つのNG。」
- **呼びかけ／限定**：「カラオケの点数が伸び悩んでる人へ。」
- **共通の敵**：「ボイトレ動画を100本見ても上達しない理由。」
- **結果先出し**：「1日30秒で、声の通りが変わった話。」

NG：説明から入る／専門用語で始める／1行目にURL。

## 3. 投稿の組み立て（共通ルール）
- **1投稿1メッセージ**。詰め込まない。
- **改行で“間”を作る**（スマホで読みやすく＝滞在↑）。
- **結論を先に**。
- **本文にリンクを置かない**→ 必要なら**自己リプに「🔽ここから無料診断 URL」**。
- **画像は2〜4枚**（診断キャラ／結果カード／図解）。
- 末尾CTAは**会話 or 保存**を促す：「リプで教えて」「保存しておくと便利」。
- **ハッシュタグは2〜3個**まで（盛り過ぎは逆効果）。#声診断 #ボイトレ

## 4. 初速の作り方（最重要・手動）
投稿後30分が勝負：
1. 出したら**すぐ自己リプ**でリンク／補足を足す（会話の起点）。
2. 来たリプに**全部 即返信**（リプ往復が最強シグナル）。
3. 同じ時間に**歌・カラオケ・ボイトレ界隈のポストへ自分からリプ**して回遊を作る。
→ 自動投稿“だけ”では伸びない。**自動=種まき、手動=点火**。

## 5. 投稿カレンダー（新規30日・1日1〜2）
| 曜 | 主な型 | 時間 |
| --- | --- | --- |
| 月 | 自己分類フック（診断誘導） | 21–23 |
| 火 | 番号付きTips | 12 or 21 |
| 水 | 声タイプ図鑑（1種紹介・画像） | 21–23 |
| 木 | **共感あるある**（最優先） | **夜21–23** |
| 金 | 逆張り／Before→After | 21–23 |
| 土 | 問いかけ（リプ狙い） | 12–15 |
| 日 | **ビジュアル投稿**（結果カード等） | **午後14–17** |

## 6. 新規アカウントの“凍結回避”
- 立ち上げ初期は**リンクを連投しない**（本文リンクは元々NG、リプリンクも1日数回まで）。
- 自動投稿は**1日1〜2**から。素の共感ポストも混ぜる。
- 同一文の使い回しを避ける（テンプレは“型”で、文面は都度変える）。

## 7. X Premium（認証）は要るか
- 認証アカウントは**リーチ優遇＋長文投稿＋リンクのペナルティ軽減**。本気で伸ばすなら投資価値あり（月1,000円台）。
- ただし本プロジェクトは“ゼロ円”方針。**まずは無料で型を回し、手応えが出たら課金を検討**でOK。

## 8. 自動投稿スクリプトへの反映
`scripts/sns_autopost` を本研究に合わせて更新：
- **本文とリンクを分離**し、**リンクは自己リプに投稿**（本文リンクのペナルティ回避）。
- 文面テンプレを上記の「型」に差し替え（共感・自己分類・Tips・図鑑）。
- 詳細は同フォルダ README。**自動は種まき**として使い、**初速の点火は手動**で。

## 9. 正直な前提
- 「型」は打率を上げるが、**バズは確率**。最初の数十フォロワーは人力（自分の発信・知人）で作る。
- 新規はとにかく**初速**。出して終わりにせず、30分は張り付く。
- 計測（どの型が伸びたか）を見て、`themes.py` を勝ちパターンに寄せていく。

**運用への影響（ソラ先生）**
- 本文リンクなし（`POST_LINK=0`）の方針は2026年3月ペナルティ強化でさらに正当化。継続。
- リプを稼ぐ型（contrarian / tip + 自己リプ）を優先する現行構成は引き続き有効。
- 初速ウィンドウ: 自動投稿後 **30〜60分以内**に手動でリプ・近隣アカウントへの返信を行う（優先度:高）。
- 縦並び画像（2〜4枚スワイプ）= 滞在時間↑ → 声タイプ図鑑カードに応用余地あり。
