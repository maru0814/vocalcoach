# 会話FBの自然化・ツール化・録音意図判定 テスト計画

対象PR: #118（4コミット）。関連設計: docs/44（ソラ先生ツール化）。関連要件: docs/36（会話型FB, FR-01/02/03）。FB品質正本: docs/42。

## 1. スコープ
Web版コーチング（`backend/app/coaching/`, `backend/app/api/v1/endpoints/coach.py`）のチャット返答・録音FBの「意図に沿った応答」を検証する。今回の4修正が対象:
1. フォローアップのテキスト質問が「録音を今解析したかのFB講評」で返らない（FR-01）。
2. 「お手本／動画」等の参考例要求が、話題に沿った実在動画を返す（FR-03, docs/44）。
3. ソラ先生ツール化: `find_reference_video` の実データ供給・強制呼び出し・カタログ外URL除去・feature flag（docs/44）。
4. 録音の意図判定: 勧めた基礎練の実演を「曲の歌い直し」と誤認しない（FR-02）。

**スコープ外**: 音声解析アルゴリズム自体（analyzer）、zero-base FB（既定OFF）、frontend UI、課金。

## 2. 対象機能要件
- **FR-01** 録音FBの会話文化 / テキスト質問は会話の続きとして自然に答える（docs/36）。
- **FR-02** 苦手検知時の練習提案と、その実演の達成判定（docs/36）。
- **FR-03** 参考動画の会話内リンク化（docs/36）。
- **docs/44** 事実（動画URL）はツールで実データのみ供給・捏造ゼロ。

## 3. テスト観点
- **正常系**: 意図どおりの応答（質問→会話、動画要求→実URL、基礎練実演→課題の達成判定）。
- **異常系**: 存在しない話題の動画要求／LLM不可／カタログ外URLの混入。
- **境界値**: ツールループ上限、`classify_kind` の practice/song 境界（音数≤3 かつ 音域≤4半音）。
- **状態遷移**: 初回診断→課題確定→基礎練実演→歌い直し の遷移で kind 判定が化けない。
- **文脈依存(照応)**: コーチが出した話題を指す「お手本ない？」だけで話題解決。
- **セキュリティ**: プロンプトインジェクションでも外部URLを出さない（カタログ外URL除去）。
- **回帰**: 既存の会話型FB契約（点数/カードを出さない）を壊さない。

## 4. テスト環境
- 単体(hermetic): `cd backend && ./.venv/bin/python -m unittest tests.test_conversational_fb`。LLM無効（`_complete→None`）で決定論部分を検証。DB・ネットワーク不要。
- 実Gemini e2e: `GEMINI_API_KEY` を `.env` から export、`coach_tools_enabled=True`、`llm_model=gemini-flash-lite-latest`(本番の雑談モデル)。温度依存のため各ケース複数試行。
- スクリプト: `scratchpad/e2e_tools_reply.py`（ツール化）, `e2e_intent.py`（意図判定）, `e2e_followup_reply.py`（FR-01）。

## 8. 残課題・別対応候補
- **R-1**: `_wants_reference` を含まない言い換え（例「どんな感じ？」等の間接要求）は AUTO 依存で拾い漏れ得る。頻度を見て hint 追加。
- **R-2**: `resolve_kind` はヒューリスティック（`classify_kind` の音数・音域＋課題文脈）。真の音声意味理解が要る場面は zero-base FB（LLMが生音声を聴く経路、既定OFF・¥コスト）を on にする判断が要る。特にサイレン/スケール等「音域が広い基礎練」は classify_kind が song 寄りに誤るため、必要なら基礎練ボタン(明示 practice)で送るか判定強化を検討。
- **R-3**: HTTP e2e（`send_message`/`send_audio` を実DBで叩く）は本計画では単体＋関数e2e止まり。CI 化するなら別途。

## 9. 判定
今回の4修正は受け入れ基準を満たす（hermetic 20 green＋実Gemini で症状の是正を実測）。**リリース可**。残課題 R-1〜R-4 は非ブロッカー。本番反映は `sre` へ、告知が要るなら `marketer` へハンドオフ。
