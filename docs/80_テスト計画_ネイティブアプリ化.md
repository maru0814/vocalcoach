# ネイティブアプリ化 テスト計画

- 作成日: 2026-07-21
- 作成: QAエンジニア
- 対象: docs/78_機能要件書_ネイティブアプリ化.md（FR-01〜07 / AC-01〜08）、docs/79_設計書_ネイティブアプリ化.md

## 1. スコープ
- `native/`（Capacitor シェル・Android/iOS プロジェクト・起動シェル）
- frontend の FR-05 分岐（appMode.ts / UpgradeModal / PremiumWidget / settings）
- `.github/workflows/native-android.yml`（CIビルド）
- 対象外: Web版既存機能そのものの回帰（変更が isNativeApp()=false 経路に無いことのコード確認で代替）

## 2. テスト環境
- **環境A（静的・CI環境）**: リポジトリ内検証＋GitHub Actions。実機不要。
- **環境B（ブラウザ）**: PCブラウザで本番/ローカルに `?source=app` を付けてアクセス（FR-05 の実機なし検証。設計 docs/79 10章のとおり UA 判定と同一コードパス）。
- **環境C（Android実機/エミュレータ）**: CI Artifacts の `app-debug.apk` をインストール。リリース判定の最終ゲート。

## 3. テスト観点
正常系 / 異常系（オフライン・権限拒否・不正URL）/ 状態遷移（起動シェル→本体）/ セキュリティ（鍵・cleartext）/ 規約（課金導線）
