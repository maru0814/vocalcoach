# 段階的エンゲージメント（初回は録音だけでOK） 機能要件書

## 1. 概要
- **一言説明**: 初回のFB依頼を「録音1本だけ」でフルに受け付け、原曲提供・練習メニューは会話の中の「問いかけ」経由でのみ深掘りする、段階的なエンゲージメント設計に改める。
- **解決する課題**: 現状は初手から「曲名・区間・原曲参照（YouTube URL等）を全部そろえてから次へ進む」（`vocal-trainer/references/coaching-loop.md` Phase A）＋「課題があれば毎回基礎練＋動画URL＋再録音要求」（SKILL.md Phase B）という作法になっており、**初回のハードルが高い**。気軽に録音を送って感想を聞きたいユーザーが離脱する。

## 2. 想定ユーザー / ユースケース
- **ペルソナ**: カラオケ・宅録レベルの独学シンガー。専門用語や手順を知らず、「とりあえず聴いてほしい」「これってミックスボイス？」程度の温度感で始めたい。
- **主要ユースケース**:
  1. 録音ファイルだけ渡して「聴いて」→ 感想と気づきが返り、深掘りの選択肢を提示される
  2. 録音＋質問（「サビの高いとこどう？」「これミックス？」）→ まず質問に答えてもらえる
  3. 会話の流れで「もっと上手くなりたい」→ そこで初めて練習メニューの相談が始まる

## 4. ユーザーストーリー
- US-01: 独学シンガーとして、録音1本だけ送って感想をもらいたい。なぜなら曲名や原曲URLを準備するのが面倒で、まず聴いてほしいだけだから。
- US-02: ユーザーとして、「この声はミックスボイスか？」のような質問に最初に答えてほしい。なぜなら自分の関心事が置き去りのまま練習を指示されると押し付けに感じるから。
- US-03: ユーザーとして、もっと詳しく知りたくなったときに「原曲をくれたら細かく比べられる」と教えてほしい。なぜなら何を渡せば何が得られるのか知らないから。
- US-04: 上達したいユーザーとして、自分が望んだときに自分に合わせた練習メニューを組んでほしい。なぜなら毎回勝手に基礎練を出されると会話でなく採点に感じるから。

## 5. 機能要件

### FR-01: エンゲージメントレベルの定義
- **概要**: FB体験を3レベルで定義し、上のレベルはユーザーの意思表示（問いかけへの同意、または明示的依頼）でのみ発動する。
- **詳細仕様**:
  | レベル | 内容 | 発動条件 |
  | --- | --- | --- |
  | **L0 気軽なFB** | 録音1本だけで受け付け、感想・気づき・質問への回答を返す | 録音が1本ある（それ以外の情報は一切不要） |
  | **L1 深掘りオファー** | 応答の最後に「次の一手」を最大1つ問いかける（原曲比較 or 練習メニュー） | L0 の応答時に自動（強制ではなく提案） |
  | **L2 コーチングループ** | 基礎練処方→確認→再録音判定（既存 Phase C〜E） | ユーザーが L1 の問いかけに乗った、または明示的に依頼した時のみ |
- **例外ケース**: ユーザーが初手から原曲・練習依頼を持ち込んだ場合はレベルをスキップしてよい（FR-05）。

### FR-02: 初回受付の最小要件（L0）
- **概要**: 録音1本があれば、曲名・区間・原曲・自己申告がすべて未提供でもフルに解析・FBする。
- **詳細仕様**:
  - 不足情報を理由に応答を保留しない。「揃うまで追加質問して待つ」ゲートを置かない。
  - 曲名・区間等を尋ねてよいのは、FBを返した**後**に会話として軽く聞く場合のみ（必須扱いにしない）。
  - 原曲が無い場合の制約は既存の事実忠実性ルール（42 §5）に従う: 音程の「正確さ」を断定せず「安定度」で語る。
- **入出力**: 入力=録音ファイル1本（＋任意の依頼文）。出力=L0 応答（FR-03）。

### FR-03: 初回応答（L0）の構成
- **概要**: 初回応答は「質問への回答＋褒め＋気づき1点＋問いかけ最大1つ」で構成し、**基礎練の処方を含めない**。
- **詳細仕様**:
  1. ユーザーの質問があれば**最初に**それに答える（FR-04）
  2. 良かった点を1つ以上、具体的な位置（秒数）つきで褒める
  3. 気づいた発声ポイントを1つだけやさしく伝える（機構→原因まで。処方＝練習はここでは出さない）
  4. 最後に L1 の問いかけを最大1つ（FR-06）
  - 「やってみて録音を送ってね」「この基礎練をやってみよう」等の練習指示・再提出要求を初回応答に含めない。
  - 参考動画URLも初回応答では出さない（練習を出さないため、対応する実演動画が不要）。
- **例外ケース**:
  - 録音が歌でない・解析不能の場合は従来どおりその旨を伝えて聞き直す。
  - **安全例外（最優先）**: 痛み・嗄れの申告や強い喉締めなど voice-health のレッドフラグ相当の兆候があるときは、L2 ゲートを待たずに安全上の助言（休声・受診の線引き）を初回応答に含めてよい。これは練習処方ではなく安全対応であり、本要件のゲートの対象外。

### FR-04: 質問優先応答
- **概要**: 録音に質問が添えられていたら（「これミックス？」「サビどうだった？」）、応答の先頭でその質問に答える。
- **詳細仕様**:
  - 質問への回答は既存の事実忠実性ルールに従う（声区は音響からの推定であることを添える等、42 §5）。
  - 質問が特定区間への注目指示（「2番のサビを聴いて」）なら、FBの中心をその区間に置く。
  - 質問に答えた後の構成は FR-03 の 2〜4 に従う。

### FR-05: レベルスキップ（ユーザー主導の深掘り）
- **概要**: ユーザーが最初から材料や意思を持ち込んだ場合、問いかけを待たずに該当レベルで応答する。
- **詳細仕様**:
  - 初手で原曲参照（URL/ファイル/曲名+アーティスト）が与えられた → 従来どおり原曲比較FB（L0+比較）。
  - 初手で「練習メニュー作って」「基礎練見て」と依頼された → L2 で応答（既存 Phase C/D の作法）。
  - 基礎練録音の確認依頼（既存 Phase D）はこれまでどおり単独で受け付ける。

### FR-06: 深掘りオファー（L1 問いかけ）
- **概要**: L0 応答の末尾に、次の一手の提案を**最大1つ**添える。
- **詳細仕様**:
  - 選択肢は2系統: (a) **原曲比較**「原曲（お手本）をもらえたら、音程の正確さまで細かく比べられますよ」／(b) **練習メニュー**「もっと伸ばしたいなら、あなたに合わせた練習メニューを一緒に作りましょうか？」
  - どちらを出すかは**気づきで伝えた課題の系統に合わせる**: 音程・原曲再現系の気づきやその方向の関心→(a)、発声・上達系の気づきや上達意欲の表明→(b)。判断材料が無ければ (a) を既定とする（提供物が軽く、次のFB品質が上がるため）。
  - 2つ同時に並べない。箇条書きメニュー形式にしない（会話文のまま）。
  - ユーザーが問いかけに乗らず別の話を続けたら、同じオファーをしつこく繰り返さない（次に自然な文脈が来るまで出さない）。
- **例外ケース**: 大きな課題が無い良い録音は、オファー無しで褒めて終えてもよい（既存ルール踏襲）。

### FR-07: 練習処方の発動条件（L2 ゲート）
- **概要**: 基礎練の処方（＝既存 Phase C 相当）は、ユーザーの意思表示があったときのみ開始する。
- **詳細仕様**:
  - 意思表示 = L1 問いかけへの同意（「作って」「教えて」）、または明示的な練習依頼・上達相談（「どうすれば直る？」も含む）。
  - 発動後は既存基準を全面適用: 練習は1つ・道具不要・5点粒度（準備→姿勢→動き→チェックポイント→ありがち失敗）・実演動画URL添付・練習をコロコロ変えない（42 §6）。
  - 「どうすれば直る？」のような質問は意思表示とみなす（質問に答える形で処方してよい）。

### FR-08: 正本と両チャネルへの反映
- **概要**: 本要件を `docs/42_FB品質基準_単一ソース.md` に新節「初回受付と段階的エンゲージメント」として追加し、両チャネルに同一PRで反映する。
- **詳細仕様**:
  - 42番: L0/L1/L2 の定義と初回応答の作法を「両チャネル共通の不変ルール」に追加。
  - skill: `SKILL.md`（Phase A/B の記述・共通ルール）と `references/coaching-loop.md`（Phase A の必須ゲート撤廃）を更新。矛盾していた SKILL.md 64行目（相談だけでもOK）を正本ルールに昇格・統一。
  - Web版: `llm.py` SYSTEM_PROMPT の初回応答部分（「必要なら練習を1つだけ…やってみて録音を送ってねと促す」）を L0/L1/L2 ゲートに合わせて修正。

## 6. 非機能要件
- **UX**: 初回応答の長さは既存基準を踏襲（2〜4文・問いかけ込みでも会話のテンポを守る）。
- **保守性**: レベル定義・発動条件は42番のみに書き、skill/llm.py は42番の表現を転記する（二重定義しない）。
- **一貫性**: ソラ先生のペルソナ・事実忠実性・練習継続原則（42 §1/§5/§6）は一切変更しない。

## 7. 受け入れ基準
- AC-01: 録音1本のみ・依頼文なしで依頼 → 応答が返り、基礎練の処方・再録音要求・原曲/曲名/区間の必須要求・動画URLのいずれも含まれない。
- AC-02: 録音＋質問（例「これミックスボイス？」）→ 応答の先頭で質問に回答している（声区推定の限界の言及つき）。
- AC-03: L0 応答に含まれる問いかけ（オファー）は最大1つで、原曲比較 or 練習メニューのどちらか一方である。
- AC-04: L0 応答の後、ユーザーが練習に同意・依頼するまで基礎練処方が出ない。同意後は練習1つ＋動画URL＋5点粒度で処方される。
- AC-05: 初手から原曲参照つきで依頼 → 追加の問いかけゲートなしで原曲比較FBが返る。
- AC-06: `references/coaching-loop.md` に「全部そろえてから次フェーズに進む／揃わなければ Phase A に留まる」に相当する記述が存在しない。
- AC-07: 42番・SKILL.md・llm.py の3箇所でレベル定義・発動条件に矛盾がない（42番が正本）。
- AC-08: 原曲なしの L0 応答で音程の「正確さ」を断定していない（「安定度」表現、既存 42 §5 の回帰確認）。
