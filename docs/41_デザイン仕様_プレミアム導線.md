# プレミアム導線強化 デザイン仕様

## 1. ユーザーゴール

ログイン済みの無料ユーザーが、上限に達する前に自発的にプレミアムプランを発見・契約できる。

## 2. 画面一覧

| ID | 画面名 | パス | 目的 |
|---|---|---|---|
| SCR-01 | 認証済みヘッダー | 共通コンポーネント | 残回数・アップグレードボタンを常時表示 |
| SCR-02 | 録音一覧 | /recordings | 既存（ヘッダー追加のみ） |
| SCR-03 | 録音アップロード | /recordings/new | 既存（ヘッダー追加のみ、ページ内バッジは維持） |

## 3. 画面ごとの仕様

### SCR-01: 認証済みヘッダー（AppHeader）

**目的:** どのページでも「残り回数」と「プレミアムへの入口」を1タップで見つけられる

**主要要素:**
- 左: ブランドロゴ（`BrandWordmark`）
- 右: プラン状態に応じたウィジェット

**状態別の右側表示:**

| 状態 | 表示内容 |
|---|---|
| 無料 / billing無効(残回数あり) | `残り X 回` バッジ ＋ `プレミアムにする ¥800/月` ボタン |
| 無料 / 残り3回以下 | `残り X 回 ⚠️` バッジ（アンバー色）＋ ボタン |
| 無料 / 残り0回 | `上限に達しました` バッジ（赤）＋ ボタン |
| プレミアム | `✓ プレミアム` バッジのみ（ボタン非表示） |
| ローディング中 | 何も表示しない（ちらつき防止） |
| billing_enabled=false | 何も表示しない |

**ボタン文言・スタイル:**
- 文言: `プレミアムにする ¥800/月`（モバイルは `¥800/月` に省略）
- スタイル: `bg-brand-gradient` の角丸ボタン（既存LPの `無料で始める` ボタンと同系統）
- タップ → `UpgradeModal` を `source="limit"` で表示

**バッジ文言:**
- 通常: `今月 残りX回`
- 3回以下: `今月 残りX回 ⚠`（テキストアンバー）
- 0回: `今月 上限`（テキスト赤）
- プレミアム: `✓ プレミアム`（テキストグリーン）

**アクション:**
- バッジをタップ → `UpgradeModal` を開く（プレミアムユーザーはタップ不可）

### SCR-02: 録音一覧（既存ページへのヘッダー追加）

既存の `RecordingsPage` の先頭に `<AppHeader />` を追加するのみ。
ページ内の「🔒 ほかN件」の導線は維持。

### SCR-03: 録音アップロード（既存ページへのヘッダー追加）

既存の `NewRecordingPage` の先頭に `<AppHeader />` を追加するのみ。
ページ内の残回数バッジ（remaining）は`AppHeader`と重複するため**削除**する。

## 5. デザイントークン

既存の `globals.css` / Tailwind設定を踏襲:

- **ブランドボタン**: `rounded-full bg-brand-gradient px-4 py-1.5 text-sm font-bold text-white shadow-soft`
- **バッジ通常**: `text-xs text-gray-500`
- **バッジ警告**: `text-xs font-semibold text-amber-600`
- **バッジ上限**: `text-xs font-semibold text-red-600`
- **バッジプレミアム**: `text-xs font-semibold text-green-600`
- **ヘッダー背景**: `border-b bg-white/90 backdrop-blur`（ログイン後は常時白）

## 6. アクセシビリティ要件

- バッジとボタンに `aria-label` を付与（スクリーンリーダーで残回数が読み上げられる）
- `UpgradeModal` は既存実装の `role="dialog" aria-modal="true"` を維持
- キーボードフォーカス: ヘッダー内のボタンはTabキーで到達可能
