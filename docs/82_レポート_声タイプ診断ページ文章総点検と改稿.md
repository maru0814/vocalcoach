# 声タイプ診断ページ 文章総点検と改稿レポート

- 実施日: 2026-07-26〜27
- 動機: 診断結果の文章について「意味が伝わりづらい」「AIっぽい」「内容が薄い」の3観点で離脱要因になっていないかの総点検（ユーザー発案）
- 対象: `frontend/src/content/voiceProfiles/` 8タイプ本文（正本: docs/62）計約23,000字・208段落

## 1. 検査手法

| レンズ | 方法 | 規模 |
| --- | --- | --- |
| 横断決定論計測 | 8ファイル横断の8字n-gram共有・語尾頻度・書き出し定型・構文テル集計（soar_eval の naturalness_metrics と同発想） | 機械 |
| 伝わりづらさ | 読者ペルソナ（20代カラオケ好き・専門知識ゼロ・流し読み）実読×8タイプ。逐語引用必須 | 8エージェント |
| 薄さ | ブラインド帰属テスト: タイプ名・固有名詞を伏せた208段落の出典当て＋バーナム文判定 | 4エージェント |
| AIっぽさ | 8タイプ読み比べの横断監査×2フォーカス（構文/語彙） | 2エージェント |
| 裏取り | 全指摘に敵対的検証（判定基準は「読者を止めるか」のみ。迷ったら棄却） | 10エージェント |

soar_eval の運用知見（裏取り無しのLLM審査は過大検出する）を適用。実際、伝わりづらさの指摘39件中、裏取り生存は**1件のみ**だった。

## 2. 確定した問題と修正

### 問題1【sev3】締め・書き出しのテンプレ文が8タイプで逐語一致
「ひとつでも『確かに』と思ったなら〜証拠です」「あなたが選ぶべきなのは〜」「〜曲は、あなたのためにあります」「最後に、ひとつだけ覚えて帰ってください」「参考アーティストなら〜この3組に共通するのは」等が全タイプ同文。読者は自分と友達のタイプを読み比べるため、2ページ目で雛形が露呈する。
→ **修正: 85箇所を各タイプの基幹比喩（矢・柱・隣・夜・光・主題歌・木漏れ日・ベルベット）で書き分け。** 修正後の横断計測で、4タイプ以上共有の最長フレーズは「このタイプには、」等の一般接続句のみになった（テンプレ文消滅）。頻出語尾「〜証拠です。」13回も上位から消えた。

### 問題2【sev3】「性格」セクションが薄く、精読離脱点
ブラインド帰属で性格セクションのバーナム率63%（19/30段落。voice/songs/ledeは0%）。独立に、ペルソナ実読が8タイプ中7タイプで「長文3連直後の性格で精読をやめる」と予測。
→ **修正: ①性格を「あるある」の後ろへ移動**（箇条書きを先に置く。ユーザー指示）**②バーナム段落に「声質→性格」の因果と固有シーンを注入**（pop/crystal/whisper/groovy/moody）。

### 問題3【sev2】個別指摘（裏取り生存分）
- dramatic 第一文の常用外漢字「翳り」→ 読み仮名を付与、「高いまま、翳れる」→「高いまま、切なくなれる」
- moody/mysterious の帰属的中率が最下位（19/27・19/25）→ 判別不能段落に固有ディテール増補（mysterious「歌の感想が後日に来る」等）。ページ内で重複していた「騒がしい店で通らない」記述も統合

### 白判定（直さないと決めたこと）
断定調・比喩・「——」・他タイプ引き合い・カラオケ語彙は意図された文体として機能（裏取りで38件棄却）。平準化はむしろAI文化を招くため実施しない。6セクション構造の共通化は仕様であり問題ではない。
