# 意思決定: アプリ版は「ネイティブ見送り・PWA化で行く」

> **[2026-07-21 上書き]** 本決定はオーナー指示により docs/77_意思決定メモ_ネイティブアプリ化.md で上書きされた。ネイティブアプリ版を実施する。

- 日付: 2026-07-17
- 起案: CEO
- 論点: 「アプリ版をリリースすべきか」。歌の録音プロダクトとしてネイティブアプリ（App Store / Google Play）に出す価値があるか。

## 選択肢
- **A: ネイティブアプリ版**（iOS/Android。React Native/Flutter/Expo 等で別開発）
- **B: PWA化**（現行 Web版をホーム画面追加・プッシュ通知・オフライン対応の「アプリ体験」に格上げ。コードは Web版のまま）
- **C: 何もしない**（Web版のまま）

## 決定: **B（PWA化）**。ネイティブ（A）は当面 Later。

## 理由（判断軸との対応）
判断軸は claude.md の CEO 判断軸（①ユーザー本質価値 ②MVP原則 ③一人で運営可能か ④収益化の道筋）。

- **③一人で運営可能か → Aは明確にNG。** ネイティブは iOS/Android 二重開発・OS更新追随・端末断片化・ストア審査で、solo運営の可処分時間を食い潰す。これ単体で却下理由。
- **②MVP原則 → Aは反する。** そもそも Web版で牽引が出ていない（診断累計7件・SNS投稿パイプライン3週停止＝認知の詰まり）。プロダクトチャネルを増やす前に既存チャネルで牽引を作るのが「完璧より公開」の筋。ストア審査はWeb版の「即デプロイ」強みも殺す。
- **①ユーザー本質価値 → メリットの9割はBで取れる。** ネイティブの利点（録音UX・プッシュ通知による習慣化）のうち、ホーム画面追加・Web Push・オフライン・そこそこの録音は PWA でカバー可能。ネイティブが明確に勝つのは「バックグラウンド録音」「マイク最高品質」程度で、現状の課題順位では優先度が低い。
- **④収益化 → Aは悪化。** ストア手数料 15〜30% は現行 ¥800/月・Stripe3.6% の単位経済を崩す。LTVが未成立の今、飲む理由がない。加えて Apple $99/年・Google $25 が「固定費ほぼ¥0」哲学を破る。

## ネイティブ（A）を再検討するトリガー（Laterの条件）
以下が揃うまで着手しない（現状いずれも未達）:
1. Web/PWAでリテンションがプロダクトの武器になっている（プッシュの投資対効果が出る状態）
2. 課金者が継続的に出て、手数料30%を飲んでも黒字のLTV
3. ユーザーから録音品質・通知への実需要が上がっている

## 前提（最優先の但し書き）
PWA化より先に、**SNS投稿パイプラインの復旧＝認知の詰まり解消**が最優先（週次 2026-07-08 のエスカレーション参照）。PWAは「アプリ体験を極小コストで取る」施策であって、集客の根本問題は解決しない。

## 次のアクション（誰が何を）
- `pdm`: PWA化の機能要件書を作成（対象スコープ = manifest／ホーム画面追加／Web Push／オフライン最小／録音導線）。docs/01・02 の Web版MVP を前提に追記。
- その後 `designer`（インストール導線・通知許諾UX）＋ `architect`（Service Worker・Web Push・キャッシュ戦略）→ `frontend-engineer` 実装。
- 並行して SNSパイプライン復旧は `sre` 側で継続（本メモの範囲外だが優先度は上）。
