# 本番化と黒字化プラン（CEO意思決定メモ）

## 0. 結論（先に）
- **まず“無料・ほぼ¥0”で公開**して認知とフィードバックを取る。広告費はかけない（オーガニックのみ）。
- 本プロダクトは **限界費用がほぼゼロ**（解析はVPS内のlibrosa＝無料、テキストFBはGemini無料枠）。
  だから固定費を最小化すれば、**有料ユーザーが数人出た時点で黒字**になる。
- 黒字化は **freemium**（無料＝制限つき／有料＝無制限＋コスト高機能）で、**牽引が出てから**課金を足す。

## 1. 最小コストの本番構成
docs/08 の通り **VPS1台 + Docker Compose（Caddy＋frontend＋backend）+ SQLite**。`Dockerfile.prod` が
`alembic upgrade head` を自動実行（新テーブルも反映）。HTTPSはCaddyが自動取得。

| 項目 | 選択肢 | 月額目安 |
| --- | --- | --- |
| サーバー | **Hetzner CX22（2vCPU/4GB, ~€4.5）** か **Oracle Cloud Always Free（ARM 4core/24GB, ¥0）** | ¥0〜800 |
| ドメイン | 任意（Cloudflare等で年1,000〜1,500円） | ~¥125 |
| HTTPS / DB / 解析 | Caddy(無料) / SQLite(無料) / librosa(VPS内・無料) | ¥0 |
| LLM | Gemini 無料枠（テキスト=flash-lite）。音声=2.5-flashは従量だが低単価 | ~¥0（低volume） |
| 計測 | Cloudflare Web Analytics（無料） | ¥0 |

→ **固定費 ≈ 月¥0〜1,000**。変数費（Gemini）は低volumeでほぼ¥0。

> 推奨: 最安重視なら **Oracle Always Free**、安定運用重視なら **Hetzner**。
> CPUが律速（同時解析）なので、レート制限（既定8回/60秒）＋ `WEB_CONCURRENCY` 小さめで運用。

## 2. 最小コストの認知獲得（広告費¥0）
docs/18 ローンチプランに準拠。**コンテンツ主導のオーガニックのみ**。
- X / note / 歌い手・カラオケ Discord / YouTube・TikTokショート（「AIに歌を添削させたら的確すぎた」系）
- 武器: **正直なFB**と**原曲とのAI聴き比べ**。デモ動画1本＋Before/Afterを固定ポスト化。
- 初週KPI: 登録50・録音100・再録音率30%（docs/18）。
- 計測だけは必ず入れる（無料のCloudflare Analytics）。「どの投稿が刺さるか」を見て続ける。

## 3. 黒字化（freemium）
### 単位経済（重要）
- 1解析の限界費用 ≈ **CPU（無料）＋ テキストGemini（無料枠）**。**発音アドバイスだけがGemini音声＝従量**。
- → **コストの高い機能（発音アドバイス・無制限利用）を有料に寄せる**と、変数費が売上に連動する。

### プラン案
| | 無料 | 有料（¥500〜980/月） |
| --- | --- | --- |
| 4軸スコア・基礎練・声診断 | ◯ | ◯ |
| 録音解析 | 月N回（例: 10回） | 無制限 |
| 原曲アップロード比較 | 体験1回 | ◯ |
| 発音アドバイス（Gemini音声） | × | ◯ |
| 履歴保存 | 直近のみ | 無制限 |

### 黒字化の数字
- 固定費 月¥1,000と仮定 → **有料2〜4人で黒字**（¥980×2 or ¥500×4）。
- 目標の置き方: 無料→有料の転換率3〜5%なら、**有料20人で月商¥1〜2万**（十分に固定費＋手数料を超える）。
- 決済: Stripe（月額固定費なし・手数料~3.6%）。サブスク＋使用量上限で実装。

### フェーズ
- **Phase 1（いま）**: 全機能無料で公開。フィードバックループ（👍👎）で品質を磨き、証言を集める。
- **Phase 2（牽引が出たら／目安: アクティブ50〜100）**: 課金導入。
  実装 = ①ユーザーごとの利用回数カウント＋上限 ②Stripeサブスク ③有料機能ゲート。
- **Phase 3**: 年額割引・紹介特典・教室/講師向けプラン等で単価とLTVを伸ばす。

## 4. リスクと対応
- **CPU飽和**（解析が重い）: レート制限＋小concurrency。増えたら解析をワーカー分離（docs/07拡張）。
- **Gemini課金の暴れ**: 音声機能を有料＆レート制限の内側に置く。無料枠監視。
- **無料のまま誰も払わない**: 価値が出る“コスト高機能”を有料に寄せ、無料は導線に徹する。
