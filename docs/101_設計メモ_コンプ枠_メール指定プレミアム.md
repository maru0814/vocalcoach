# 101 設計メモ — コンプ枠（メール指定でプレミアム扱い）

- 作成: 2026-08-13（backend-engineer）
- 依頼: 運営者アカウント `yumaruyama0814@gmail.com` は課金なしでソラ先生を無制限に使えるようにする
- 関連: docs/31（有料プラン FR-01）, docs/33（設計 §2 プラン判定）, docs/52（課金者上限除外）

## 方針

プラン判定の単一入口である `billing_service.is_premium()` に「コンプ（comp = complimentary、無償提供）扱いメールの allowlist」を追加する。allowlist に載っているメールのユーザーは、Stripe サブスクの有無に関わらず常にプレミアム扱いになる。

判定を `is_premium` に足すだけで、以下のゲートがすべて一括で解放される（各ゲートは追加改修なし）:

| ゲート | 場所 | 効果 |
| --- | --- | --- |
| 解析回数上限（月10回） | `billing_service.analysis_allowed` | 無制限 |
| 解析カウント加算 | `billing_service.increment_analysis_count` | カウントされない（FR-01 既加入者と同じ） |
| 履歴表示件数上限 | `endpoints/recordings.py` | 無制限 |
| ゼロベースFBの予算ゲート | `llm_budget.zero_base_allowed` | プレミアム優先枠 |
| プランバッジ / `GET /billing/me` | `billing_service.billing_me` | `plan: "premium"`・`analysis_limit: null` |
| Checkout | `endpoints/billing.py` | 409 `ALREADY_PREMIUM`（誤課金の防止） |

## 設定

`app/core/config.py`:

```python
comp_premium_emails: str = "yumaruyama0814@gmail.com"
```

- カンマ区切り・大文字小文字は無視（小文字化して比較）。
- env `COMP_PREMIUM_EMAILS` で上書き可（追加・削除とも再デプロイ不要、再起動のみ）。
- 空文字にすればコンプ枠は無効。

## 実装

`billing_service.is_premium()` の先頭でユーザーのメールを引き、allowlist にあれば `True` を返す。DB スキーマ変更なし（マイグレーション不要）。

解析回数・履歴の各ゲートは `billing_enabled=False` の間はもともと全員素通しなので、allowlist が意味を持つのは `billing_enabled=True` のとき。ただし **ゼロベースFBの月次LLM予算（¥2000）だけは課金OFFでも全員に効く**ため、`coach.py` の `_premium` 判定から `settings.billing_enabled and` の前置きを外した。これで課金OFF運用中でもコンプ枠（と有効なサブスク保持者）は予算超過によるルールベースFB格下げの対象外になる。

`billing_me()` の `period_end` は Subscription 行が無ければ従来どおり `None`（コンプ枠に期限は無い）。

## テスト

`tests/test_analysis_limit.py` に追加:
- allowlist のメールのユーザーは上限超過してもブロックされない・カウントされない
- 大文字小文字違いでも一致する
- allowlist 外のユーザーは従来どおり上限でブロック（回帰）
