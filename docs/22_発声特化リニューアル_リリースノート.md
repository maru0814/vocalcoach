# 発声特化リニューアル リリースノート（朝の確認用）

一晩の作業で「ソラ先生」を **発声に特化した、原曲比較ベースの、プロのボイストレーナー級** に作り込みました。
本番反映済み（https://160-251-177-227.sslip.io ）。ローカルでも確認できます（下記）。

## 何が変わったか
1. **発声に集中**。リズム・抑揚（強弱）・しゃくり/こぶし/フォール等の表現要素は採点・コーチ文・課題診断から外した。
2. **原曲（お手本）と比較**して発声を語る。「原曲はサビをミックスで前に当てている／あなたは地声で押し上げ気味」のように。
3. **音声科学を根拠**に。ソース・フィルタ理論、声帯内転（H1-H2＝flow phonation）、シンガーズフォルマント、レジスター/換声点、SOVT、アンザッツ（Husler/Rabine）。出典は `docs/21`。

## 発声カード（採点）の中身
ヘッダー「🎤 発声診断（原曲と比較）」＋ 総合スコア。
- **🎙️ プロの一言総評**（最重要ポイントを headline で）
- **🎯 音程の正確さ**（原曲とのin-tune＋安定度）
- **🔊 声の鳴り・効率**（声帯の閉じ＝H1-H2／響き＝シンガーズフォルマント、各々原曲比較）
- **🪜 声区の運び**（高音の声区を原曲と比較／換声点）
- **🫁 支え・安定**（伸ばしの安定＝appoggio）
- **🎯 音を外したところ**（秒数つき、原曲照合時のみ）
- ✨ 良かった点（発声）／🎤 声の特徴チップ／🎯 今日のポイント（発声ドリル）

## コーチ文（LLM）
世界最高峰のトレーナーとして、**機構→原因→処方**で語る。例:
> 「息が少し漏れ気味（H1-H2が約9dB）なので、ストロー発声で声帯の閉じを整えると、より効率よく声が前に鳴ります」
- 原曲比較の事実を必ず根拠にする／専門語は一言で補足／捏造防止（与えられた数値・秒数・声区のみ）。

## 発声ドリル（科学的根拠）
- 息漏れ → **SOVT**（ストロー発声・リップロール）で声帯の閉じを整える（Titze）
- 響きが弱い → **プレースメント/アンザッツ**（ハミング→母音でマスクに集める）
- 高音が地声 → **ミックス**（ネイ/ハミング、軽く前当て）
- 締めすぎ → リップロールで脱力／支え → ドッグブレス＋スー、メッサ・ディ・ヴォーチェ

## 計測した発声指標（実装）
- `h1h2_db`（声帯の閉じ）, `singers_formant_ratio`（響き）, `register`（声区）, `long_tone_stability`（支え）,
  `in_tune`（原曲との音程一致）。`compare_voice` で原曲と user を比較（響き/閉じ/声区/音程）。
- H1-H2 等の絶対値はマイク・母音でドメイン依存のため、**原曲との相対差を主**に使う（単体時は控えめに表現）。

## ローカルでの確認方法
- バックエンド: `cd backend && .venv/bin/python -m uvicorn app.main:app --reload`
- フロント: `cd frontend && npm run dev`（http://localhost:3000 ）
- カード単体の見た目を素早く見たい時は、`frontend/src/app/` に一時プレビューページを作る運用（今回は確認後に削除済み）。
- 実機検証は本番で実施済み（原曲アップ→録音で発声カード＋コーチ文、応答 5〜7秒）。

## 注意・残課題
- 発声指標（特に声区・H1-H2）は推定であり、**マイク品質や声分離の影響**を受ける。原曲との相対比較が最も信頼できる。
- 原曲比較が成立するには「ユーザーが歌った区間」と「原曲の同じ区間」を合わせる必要がある（区間指定 or 「◯秒から重ねて再診断して」コマンド）。
- 旧データ（vibrato/ornaments）の解析自体は残しているが、UI・コーチ文・診断からは参照しない。
- 余力があれば: 声区の時系列（どの秒でミックスに乗れたか）、母音ごとのフォルマント整合、声区の段差（換声点の滑らかさ）の定量化。
