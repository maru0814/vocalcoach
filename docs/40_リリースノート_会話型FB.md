## コアメッセージ（一文）
**点数で採点されるのではなく、ボイトレの先生とLINEしている感覚で、今の自分にいちばん効くコツが1つだけ返ってくる。**

## 何が変わった？（ユーザー目線）
| Before | After |
| --- | --- |
| 録音すると採点カードが4枚どっと出てくる | ソラ先生が話し言葉でひとこと返してくれる |
| 「総合72点」と点数がつく | 点数はナシ。良かったところと、次に試すコツを会話で |
| 改善点が一気に羅列される | 苦手が見えたときだけ、練習を“1つ”そっと教えてくれる |
| 参考動画がカードで並ぶ | 会話の流れで「この動画わかりやすいよ」とリンクを1本 |

### 体験イメージ
> **あなた**：サビの高いとこ、声がひっくり返っちゃう
> **ソラ先生**：あー、地声で押し上げ気味かも。喉が少し詰まって聞こえます🎤
> **ソラ先生**：「ネイネイ」って鼻に響かせて1音ずつ上げると、力まずに高さを稼げますよ。録って送ってくれたら一緒に見ますね😊（参考動画 → …）

## ユーザーにとっての価値（ベネフィット）
- **採点される緊張感がない** → 気軽に何度でも歌える。続けやすい。
- **情報が多すぎない** → 「次に何をすればいいか」が毎回1つだけ。迷わない。
- **人に習っている感覚** → 質問すれば文脈を覚えたまま会話が続く。

## 既存ユーザーへの一言
これまでの採点カードの履歴は消えません。過去のレッスンも開けます（表示はシンプルになります）。今日から、同じソラ先生がもっと“人っぽく”話します。

## 告知プラン（軽量・ゼロ円運用に接続）
**ターゲット**: 独学でカラオケ・歌をうまくなりたい20〜30代。採点アプリに疲れた人。
**チャネル**: X（既存運用）、note。

| タイミング | 内容 |
| --- | --- |
| ローンチ日 | Before/After 1枚画像＋体験スクショで本告知 |
| T+3日 | 「点数をやめた理由」をnoteで（採点が続かない理由→会話型へ） |
| T+7日 | ユーザーの実会話スクショ（許諾済み）で使用感共有 |

### X投稿案（本告知）
```
歌の練習アプリ、点数つけるのやめました。

録音を送ると、AIボーカルコーチ「ソラ先生」が
LINEみたいに話し言葉で返してくれます。

・点数なし
・良かったところ＋次の一手を“1つだけ”
・苦手な発声には、その場で練習のコツ

採点に疲れた人へ🎤
```

### note見出し案
- 「歌アプリの“採点”をやめた話。点数より、続く会話を選んだ理由」
- 「『総合72点』をなくしたら、ユーザーがもっと歌うようになった（予定）」

## 成功指標（KPI・要計測）
- ローンチ後7日で、1セッションあたりの**平均往復数（メッセージ数）が増加**（会話継続の代理指標）。
- 録音後の**2回目以降の録音率**が改善（採点プレッシャー低下→再挑戦が増える仮説）。
- 7日で新規登録 N人 / FB（録音）送信 N件（既存のゼロ円集客プラン docs/23 の目標に接続）。

## 注意（誇大表現の回避）
- 「プロ並みになれる」等は書かない。実際にできるのは「今の発声の良し悪しを言葉で伝え、課題が見えたら練習を1つ提案する」こと。
- 声区・音程は音響解析からの推定であり、断定しない（プロダクト方針 docs/12 と一致）。
