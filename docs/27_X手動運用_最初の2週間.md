# X 手動運用プラン — 最初の2週間（ソラ先生）

> マーケター作成。新規アカウント（0フォロワー）を**ゼロ円**で育てるための、毎日の動き＋投稿台本。
> 投稿文の型は docs/25、Day1〜7の本文は docs/26 を併用。本書は「いつ・何を・どう動くか」。

## 0. 大前提（正直に）
- **新規は“投稿しただけ”では誰にも届きません。** 最初の数十フォロワーは「①リプ周り（自分から絡む）」「②知人への種火」「③診断シェア」で**人力で作る**。
- 投稿は“きっかけ作り”。**勝負はリプ（会話）と初動30分**。
- 目標は「バズ」ではなく **2週間で“反応してくれる人を20〜50人”作る**こと。土台ができれば後は速い。

---

## 1. 毎日のルーティン（1日 15〜20分でOK）
順番が大事。**「絡んでから投稿」**が効く。

1. **【5分】リプ周り（最重要）** … 歌・カラオケ・ボイトレ界隈の投稿に、自分から**中身のあるリプを3〜5件**。「いいね」だけで終わらせない（§3参照）。
2. **【3分】今日の1投稿** … 下の台本どおり投稿。画像が要る型は添付。**本文にリンクを入れない**（リンクは自己リプ）。
3. **【投稿後30分は張り付く】** … 来たリプ・引用に**全部すぐ返信**。リプの往復がいちばん効く。反応が無ければ自分の別の話題で1リプ足す。
4. **【2分】診断シェアを拾う** … 「声診断」「声タイプ」で検索し、診断してくれた人がいたらお礼リプ＋会話。
5. **【任意】フォロー** … 絡んだ相手・界隈の人を1日3〜5フォロー（一気に大量はNG）。

## 3. リプ周りの“狙い目”（新規が見つかる入口）
**検索して、新しめ＆伸びてない投稿に、価値あるリプを返す**（相手にもメリットを置く）。
- 検索ワード：`カラオケ 高音` `音痴 直したい` `ミックスボイス` `歌ってみた 録音` `ボイトレ` `声 コンプレックス`
- 狙う投稿：「高音が出ない」「サビで苦しい」「録音聴くと下手」等の**お悩み系**。
- リプの作法：
  - ✅ まず共感 → 具体的な小ワザを1つ → 押し付けない。例：「録音の自分、最初みんな違和感ありますよね😌 高音のとき“ため息に声を乗せる”だけで喉の力みが減りますよ🎤」
  - ❌ いきなり自社リンク／「診断どうぞ」連投（スパム扱い・逆効果）。リンクは聞かれたら or 仲良くなってから。
- 1日3〜5件、丁寧に。**“いい人”として界隈に顔を出す**のが新規の近道。

## 4. 種火（最初の反応を人力で作る）
- 知人5人に「声タイプ診断つくった、やって結果見せて」と**個別に**お願い（公開リプで盛り上がると尚良し）。
- 自分でも一度診断し、**結果カードを実例として投稿**（Day7やWeek2 Day14）。
- 「歌ってみた」「弾き語り」界隈の知り合いがいれば、感想をもらう。

## 6. 週次レビュー（毎週日曜の夜・5分）
見るのはこれだけ：
- **どの投稿のリプ/プロフ表示が多かったか** → 勝ち型を翌週に増やす。
- **フォロー increased か**（数より「会話した人」の数を重視）。
- **診断してくれた人がいたか** → いたら最優先で関係を作る。
> 数字が小さくても気にしない。**“会話が生まれた型”を残し、生まれなかった型を削る**だけ。

## 7. 「次の一手」に進むサイン
- フォロワー **100超 or 1投稿の表示が安定して数千** → 自動投稿（X API課金 月数百円）を足して**手を空ける**。
- 診断のシェアが**自然発生**し始めた → OGP・結果カードが効いている証拠。LP/シェア文をA/Bで磨く。
- ここまで来たら **計測（Cloudflare Web Analytics）** を入れて、流入元を見て投資判断。
