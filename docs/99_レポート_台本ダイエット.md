# 99. レポート — 台本ダイエット（会話SYSTEM_PROMPTの圧縮）

- 実施日: 2026-08-09（backend-engineer / qa-engineer）
- 背景: docs/98 のコスト実測で「入力7.8kトークン/ターンの大半が毎ターン同一の台本」と判明。
  docs/97（プロンプトダイエット方針）柱1・柱3 の初回実施。別セッション「決定論とLLMの組み合わせ」で
  残課題②とされていた「台本ダイエット」の実施。
- 方針: **docs/42 の方針は一切変えない**。表現の圧縮・重複排除・撤去済み機構への言及削除のみ。
  会話ターン用 SYSTEM_PROMPT が対象（分析ターンの ANALYSIS_SYSTEM_PROMPT は別途・今回対象外）。

## 1. 何を削ったか

| 節（旧） | 旧tok | 処置 |
| --- | --- | --- |
| FB（録音への講評）の作法 | 1,531 | 会話ターンに必要な核（カード無し・練習継続・動画オファー枠・原曲確認フロー・1点集中）だけ残し「レッスンの決まりごと」へ圧縮。詳細な講評作法は分析ターン（ANALYSIS_SYSTEM_PROMPT）の担当 |
| 参考知識（音声科学クリブ） | 690 | 全削除。flash-lite 時代の補助輪。3.5-flash はドメイン知識を持つ。用語の統一は「専門用語の一言補足」例示に残置 |
| 会話のルール／会話モード／質問への向き合い方 | 1,076 | 趣旨重複を統合し「会話の作法」1節へ。撤去済みの正規表現ゲートへの言及（「『# 会話モード』の指示がある時」）を削除 |
| 事実への忠実さ／解析でわかること | 713 | 重複（捏造禁止が4箇所に散在）を統合 |

**結果: 4,347 → 1,496 トークン（-66%）**。5節構成（人物像／会話の作法／事実への忠実さ／
レッスンの決まりごと／出力）。不変条件（捏造禁止・歌詞非認識・橋渡し義務・練習継続・
オファー1回・実URLのみ・原曲確認アンカー・Markdown禁止 等）は全て保持。
