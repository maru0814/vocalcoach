# 声区しきい値の較正（合成コーパス＋較正ハーネス）

## 1. 目的
声区推定（地声/ミックス/裏声）の票しきい値（`analyzer.REGISTER_THRESHOLDS`）を、
**ラベル付き音源から再現可能に較正できる仕組み**を用意する。
現状はラベル付き実音源が無いため、**声門源モデルで合成したラベル付きコーパス**で
ブートストラップ較正し、キューの妥当性と限界を定量化する。

## 2. 成果物
- `backend/tools/voice_synth.py` … 声門源（Rosenberg型）＋声道フィルタで
  地声/ミックス/裏声の合成音を生成。開放率OQ→H1-H2、閉鎖の急峻さ→傾斜、で声区を物理制御。
- `backend/tools/calibrate_register.py` … ラベル付きディレクトリ（`{chest,mix,head}/*.wav`）から
  本番と同じ測定コードで特徴抽出し、各キューのしきい値を独立に較正＋混同行列を出力。
- `analyzer.REGISTER_THRESHOLDS` … しきい値を定数化（較正で更新できる）。

### 使い方
```bash
cd backend
python -m tools.voice_synth --out data/register_synth --per-class 120
python -m tools.calibrate_register --data data/register_synth
# 実データがあれば data/register/{chest,mix,head}/*.wav に置いて --data を差し替える
```

## 3. 合成の設計（声区を物理的に制御）
| 声区 | 開放率 OQ | 速度商 SQ | 閉鎖急峻さ fc(Hz) | f0レンジ | 気息ノイズ |
| --- | --- | --- | --- | --- | --- |
| chest | 0.40–0.52 | 3.0–4.2 | 4200–6500 | 130–300 | 小 |
| mix | 0.55–0.66 | 2.1–2.9 | 2000–3200 | 250–480 | 中 |
| head | 0.72–0.85 | 1.4–1.9 | 700–1300 | 350–700 | 大 |

母音5種(a/i/u/e/o)・f0・ビブラート・ジッターをランダム化。
**音源単体でH1-H2・傾斜が声区順に単調**になることを確認済み
（例 f0=220: H1-H2 chest −1.7 / mix +2.1 / head +11、tilt も chest 浅→head 急）。

## 4. 較正結果（合成 180サンプル, 60/class）
- 現行しきい値: macro-F1 **0.538** / 正解率 0.586
- 各キュー独立較正後: macro-F1 **0.613** / 正解率 0.644
- 混同の中心は **chest↔mix**（声区推定の本質的な難所。両者は音響的に連続）。

キューは3つとも声区順に単調分離（合成・実録音とも確認）:
- スペクトル傾斜（地声=浅い/裏声=急）
- H1-H2（地声=小/裏声=大）
- **ロールオフ÷f0（最も分離が良く、f0正規化で転移しやすい）**

## 5. 重要な知見：合成の「絶対しきい値」は実録音に転移しない
較正で得た合成最適しきい値を**実録音**に当てると、**むしろ悪化**した:

| しきい値セット | 低音(<330Hz) | 高音(≥330Hz) |
| --- | --- | --- |
| 現行（実録音検証済み） | 地声 ✓ | ミックス ✓ |
| 合成丸ごと採用 | 地声 | **地声（誤）** |

理由: H1-H2・傾斜の**絶対値**はマイク・母音・声分離・フォルマント汚染でオフセットし、
合成ドメインと実録音ドメインで水準がずれる（例: 合成chestのH1-H2≈+12 vs 実録音chest≈−7）。
- フォルマント補正（Iseli-Alwan）も試したが、chest/mix を圧縮し分離は改善せず → 不採用。

## 6. 決定（本番方針）
- **本番しきい値は実録音検証済みの現行値を維持**（合成の絶対しきい値は採用しない）。
- 較正ハーネスと合成コーパスを**資産として整備**し、しきい値は**定数化**。
- **実ラベル音源（地声/ミックス/裏声の歌唱）が集まり次第**、同ハーネスで較正→
  `REGISTER_THRESHOLDS` を更新（人がレビューして反映。自動上書きはしない）。
- 転移しやすい **ロールオフ÷f0 を主軸**として今後重み付けを検討。

## 7. 限界・今後
- 合成は声門源の理想化で、実声の個人差・録音条件を完全には模さない。
- chest↔mix は本質的に難しく、最終的には**少量でも実ラベル音源**が精度を決める。
- 収集案: 既存ユーザー録音に対し、ボーカルトレーナー（人）が声区をラベリングして
  `data/register/` に蓄積 → 月次で較正を回す。
