## 設計方針
- 差出人はソラ先生名義。トーンは docs/42 §1（わたし・やわらかい敬体・絵文字0〜2個）。
- CTAは1つだけ: 初回録音（`{frontend_base_url}/coach`）。声診断・プレミアムには触れない。
- 抽象的な比喩は使わない。何ができるかをストレートに書く。
- プレーンテキスト（HTMLなし）。300字以内。
- フッターに運営者連絡先を明記（特定電子メール法配慮。docs/84 FR-04）。

変数: `{cta_url}` = `settings.frontend_base_url + "/coach"`、`{contact_email}` = `settings.mail_from_address`

```
こんにちは、AIボーカルトレーナーのソラです。
ご登録ありがとうございます🎵

わたしにできるのは、あなたの歌の録音を聴いて、

スマホの録音そのままで大丈夫です。

ソラ先生（Vocal Coach）
```

- 文字数: 約230字（フッター除く本文）。
- 「30秒のワンフレーズでも十分」= 初回投稿のハードルを下げる一文（登録→初回録音の離脱対策。docs/84 §1 の課題に対応）。

## 実送信の確認手順（運用者向け・キー設定後に1回）
1. Brevo でアカウント作成 → Senders で送信者アドレスを認証 → API キー発行（`xkeysib-...`）。
2. VPS `/opt/vocalcoach/docker/.env` に追記:
   `MAIL_API_KEY=xkeysib-...` / `MAIL_FROM_ADDRESS=<認証済みアドレス>`
3. backend を再起動（docs/85 §11）。
4. 自分の別アドレスで新規登録 → ウェルカムメールが届くこと・CTAリンクが本番 `/coach` を開くことを確認。
5. 届かない場合: `docker compose logs backend | grep "welcome mail"` で sent/skip/failed を確認。
