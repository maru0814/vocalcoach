## HTML版デザイン仕様（2026-08-01 追加・デザイナー）

### メールクライアント制約（実装の前提）
- レイアウトは**テーブル**、装飾は**全てインラインCSS**（`<style>`ブロック・外部CSSはGmailで不安定）。
- 画像は **https絶対URLのみ**。Gmailは data URI を表示しない。ロゴは本番配信済みの `{frontend_base_url}/icons/icon-192.png`（51KB・PWAアイコン流用）を使う。
- Web フォント不可。`sans-serif` システムフォントスタック。
- HTMLを送る時も**テキスト版を必ず同梱**（マルチパート。表示不可クライアント・スパムスコア対策）。

### 構造（1カラム・最大600px）
```
┌─ ページ背景 #f4f5f7 ────────────────────┐
│ ┌─ カード 600px・白・角丸12px ─────────┐ │
│ │ ヘッダー: 紺 #171045                  │ │
│ │   ソラのアイコン（64px・円形）        │ │
│ │   「ソラのステージ」白・16px          │ │
│ │ 本文: 白背景・#1f2937・15px/1.9       │ │
│ │   挨拶〜「30秒のワンフレーズでも…」   │ │
│ │   （テキスト版と同一コピー）          │ │
│ │ CTAボタン（中央・1つだけ）:           │ │
│ │   「録音を聴かせてください」          │ │
│ │   bg #22d3ee／文字 #0f0a2e 太字        │ │
│ │   padding 14px 36px・角丸8px          │ │
│ │ 結び: 「お待ちしていますね。」        │ │

│ └───────────────────────────────────────┘ │

```
- 冒頭に**非表示プリヘッダー**「登録ありがとうございます。録音1本で、次に練習することが分かります。」（受信一覧のプレビュー行を制御）。
- CTAはテーブル製ボタン（bulletproof button）。`<a>`のみのボタンはOutlookで崩れるため。
- ダークモード反転には抗わない（メディアクエリ非対応クライアントが多いため、単色・高コントラストで成立させる）。

### アクセシビリティ / コントラスト
- ロゴ `alt="ソラ先生"`。画像ブロック時も本文だけで意味が通る構成。
- ボタン: #0f0a2e on #22d3ee ≒ 12:1、ヘッダー: 白 on #171045 ≒ 15:1（いずれもWCAG AA以上）。
- リンクはボタンに加えフッターに素のURLも1行併記（コピー&ペースト用・リンク先の透明性）。

### 差出人アイコン（Gmailで丸く出るアバター）について
メールHTMLでは制御できない。出す方法は2つで、現構成で可能なのは(1)のみ:
1. **benfan164@gmail.com のGoogleアカウントのプロフィール写真を設定**（myaccount.google.com → 個人情報 → 写真 → `frontend/public/brand/sora-icon.png` をアップロード）。Gmail宛の受信者にはこれが表示される。反映まで数時間〜48時間かかることがある。
2. BIMI（全クライアント共通の公式手段）→ 独自ドメイン＋DMARC必須のため現構成では不可。独自ドメイン移行時に再検討。

## 実送信の確認手順（運用者向け・キー設定後に1回）
1. Brevo でアカウント作成 → Senders で送信者アドレスを認証 → API キー発行（`xkeysib-...`）。
2. VPS `/opt/vocalcoach/docker/.env` に追記:
   `MAIL_API_KEY=xkeysib-...` / `MAIL_FROM_ADDRESS=<認証済みアドレス>`
3. backend を再起動（docs/85 §11）。
4. 自分の別アドレスで新規登録 → ウェルカムメールが届くこと・CTAリンクが本番 `/coach` を開くことを確認。
5. 届かない場合: `docker compose logs backend | grep "welcome mail"` で sent/skip/failed を確認。
