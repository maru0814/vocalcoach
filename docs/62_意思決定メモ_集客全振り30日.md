# 意思決定: 集客の打ち手 — 「配信を増やす」ではなく「人のいる場所に出向く」

- 日付: 2026-07-17
- 決定者: CEO
- 論点: 流入が実質ゼロ（外部登録6週間で1人・訪問7〜21UU/日）。どこに時間を投じるか。
- 関連: docs/23（ゼロ円集客プラン）、docs/20（黒字化プラン）、docs/weekly/2026-07-08

## 前提となる事実（growth-operator 実データ調査 2026-07-16/17）

1. X投稿パイプラインは 7/9 に復旧済み。7/9〜7/16 で10本公開、1日1〜3本稼働中。
2. 6月実績の平均インプレは 17.8/投稿。1日3本×30日でも月約1,600インプレ、CTR 1%で16クリック。
   **自動投稿だけでは登録100人に数学的に到達できない。**
3. docs/23 の最重要施策「シェアできる診断カード」は実装済み
   （X/LINEシェアボタン・OGP・`/voice-type/share/[id]` 確認）。ただし診断母数
   （累計17件）が少なすぎてシェアループは着火しない。
4. docs/23 が「フォロワー0からの最速手」とした人力の動き
   （リプ・フォロー・ギフティングDM・note）は、週次レポートで3週連続
   「下書きまで用意・送信は未実行」。Tier 1 の半分と Tier 2〜3 は一度も実行されていない。
5. プロダクト側は、唯一の外部ユーザー（7/8登録）が8分でコーチングセッションを完走し
   2セッション目に入った、という n=1 の良シグナルのみ。recordings テーブルは0件だが、
   「壊れている」のか「そこまで人が来ていない」のかトラフィック不足で判定不能。
6. 7/11〜7/14 に約3日間の本番停止があり、誰も気づかなかった（死活監視なし）。

## 選択肢

- A: 現状維持（自動投稿が回っているので待つ）→ 却下。前提2の通り数学的に詰んでいる。
- B: 人力エンゲージに時間を投じる（毎日リプ3件＋手動フォロー、ギフティングDM20通、note仕込み）→ **採用**
- C: 新チャネル開拓（TikTok/YouTube Shorts、広告）→ 却下（今は）。一人運営の負荷超過・ファネル未検証。
- D: プロダクト改善で歩留まりを上げる → 凍結。直す対象を特定できるだけのトラフィックがない。

## 決定: B。開発を止め、30日間「配る」に全振りする

**理由（判断軸との対応）**:
- ユーザーの本質的価値: プロダクトは n=1 ながら完走まで機能した。今、価値を毀損しているのは品質ではなく「誰にも届いていないこと」。
- MVP原則: 作るものは足りている（診断・シェアカード・OGP・自動投稿）。未実行なのは配布だけ。
- 一人運営: リプ3件＋フォロー10人は1日30〜60分。growth-operator が毎週クエリと下書きを納品済みで、追加コストは「実際に送ること」のみ。
- 収益化: 課金導線はファネル最下流。上流が乾いている今は触っても回収できない。
