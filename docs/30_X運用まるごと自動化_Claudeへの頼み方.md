# X運用まるごと自動化 — 役割分担と「Claudeへの頼み方」

> 「投稿に限らずX運用（分析含む）を自動化したい」への設計。
> ポイントは **“機械(cron)・頭脳(Claude)・人間(あなた)” の3層に分ける**こと。全部をbotにすると質が落ち、凍結リスクも上がる。

## 1. 3層モデル（これが結論）
| 層 | 担当 | やること | 頻度 |
| --- | --- | --- | --- |
| **A. 機械（VPSのcron）** | スクリプト | 投稿（テキスト/URLなし）＋ インプレ計測 | 毎日 自動・無人 |
| **B. 頭脳（Claude／スケジュール実行）** | Claude | 分析→方針決定→文面/リプ案の生成→themes更新→報告 | 週1（必要なら日次） |
| **C. 人間（あなた）** | あなた | 公開リプの会話、関係づくり、最終承認 | 1日15分 |

- **A はもう動いています**（21:00投稿／23:00計測）。
- **B が「分析も含めた自動運用」の本体**＝Claudeに任せる部分。
- **C は自動化しないほうがいい**（後述）。

## 2. Claude（B層）に任せられること
スケジュール実行のClaudeに、毎週こう動いてもらう：
1. **データ取得**：VPSに入って `posts_log.jsonl` / `metrics_log.jsonl` を読む（先週の投稿×インプレ×エンゲージ率）。
2. **分析**：型(pillar)別に「平均インプレ・eng率・リプ率」を集計し、勝ち型/負け型を判定。
3. **トレンド調査**：Web検索で“直近伸びているX/ボイトレ界隈の型”を更新。
4. **改善反映**：`themes.py` の `PILLARS` 配分・文面テンプレを更新（PR→マージ→VPS反映）。
5. **生成**：今週の投稿7本＋「リプ周りの狙い目」＋固定ポスト更新案を docs にまとめる。
6. **報告**：何をどう変えたか・来週の狙いを1枚で報告。

→ これで「投稿・計測・分析・改善・次の企画」までが回る。**あなたは報告を読むだけ**。

## 3. 自動化“しない”ほうがいいもの（正直に）
- **見知らぬ人への“リプ周り”**：新規が伸びる主エンジンだが、botでやると**スパム判定・凍結**＋中身が薄くて逆効果。→ **人間が手で**（Claudeは「狙い目リスト＋返信文の下書き」まで）。
- **メンションへの自動返信**：誤爆・塩対応で信頼を失う。→ **「Claudeが下書き→あなたが承認して送信」**が安全。
- **自動フォロー/自動いいね連打**：凍結リスク大。やらない。
- **DM一斉送信**：完全NG（規約違反・スパム）。

> X規約：**自分のアカウントの投稿自動化はOK**。攻撃的な自動フォロー/リプ/DMはNG。だから「投稿＝自動／会話＝人間」が安全で、しかも伸びる。

## 4. Claudeへの“頼み方”（実際の運用方法）
### (a) 定期実行で任せる（おすすめ）
`/schedule` で**週次のClaudeジョブ**を作る。依頼文の例（コピペ可）：
```
【X週次オペレーション @Sorawngg】毎週月曜9時に実行：
1. VPS(/opt/vocalcoach/scripts/sns_autopost)の posts_log.jsonl と metrics_log.jsonl を読み、
   型(pillar)別の平均インプレ・エンゲージ率を分析。
2. 直近のX/ボイトレ界隈で伸びている型をWebで調査。
3. 勝ち型に合わせて themes.py の PILLARS と文面テンプレを更新（PR→マージ→VPS git pull）。
4. 今週の投稿7本・リプ周りの狙い目・固定ポスト更新案を docs にまとめて報告。
制約：月2000円以内／本文URLなし(POST_LINK=0)／公開リプと実会話は私がやるので“下書き”まで／
      大きな方針変更や費用増は私に確認してから。
```
### (b) その都度頼む（スポット）
「先週のX分析して、来週の投稿とリプ案を出して」とチャットで言うだけ。Claudeがログを見て分析→提案。

### (c) 日次の“返信ドラフト”を足したい場合
「毎日23時に、自分のポストへのリプ/メンションを取得して、返信文の下書きを作って（送信はしない）」という日次ジョブも追加可能。**送信はあなたが承認**。

## 5. うまく頼むコツ（プロンプトの勘所）
- **スコープを明示**：「投稿・分析・themes更新は自動／公開リプは下書きまで」。
- **ガードレールを書く**：予算・URLなし・凍結回避（連投/自動フォローしない）。
- **承認ゲート**：「方針変更・費用増は確認してから」。
- **成果物の形を指定**：「PRで反映」「docsに1枚で報告」。
- **アカウントを明示**：@Sorawngg。

## 6. 今の状態と次の一手
- A層（投稿・計測）：✅ 稼働中（cron）。
- B層（分析・改善・企画）：**`/schedule` で週次Claudeジョブを作れば完成**。
- C層（会話）：あなたが1日15分。
→ まずは**週次ジョブを1本**作るのが、最小の手間で“まるごと自動化”に一番効く。
