# 声区推定の精度向上（フォルマント併用） 設計書

## 1. 背景・課題
声診断カードの「使っている声（推定）＝地声/ミックス/裏声」と「換声点（推定）」は、
現状 **スペクトルロールオフ85% ÷ f0 の比だけ**（`_voice_type`）で判定している。

```
rolloff_to_f0 >= 6.0 → chest(地声) / >= 4.0 → mix / < 4.0 → head(裏声)
```

この単一指標には次の弱点がある:
- **明るさ（音色）と声区を混同**する。母音・マイク・全体の明るさで大きくぶれる。
- 声区の音響的相関として弱い（声区は主に**声門源の特性**で決まる）。
- 信頼度が無く、粗い推定でも断定的に1ラベルを出してしまう。

## 2. ゴール
複数の音響特徴を併用して声区推定を頑健化し、**信頼度**を付ける。
不確かなときは「判定が難しい」と正直に出す（反ハルシネーション方針の継続）。

## 3. 採用する音響特徴（声区の相関）
| 特徴 | 算出 | 声区との関係 | 検証 |
| --- | --- | --- | --- |
| **スペクトル傾斜** (dB/oct) | 0.3–4kHz の対数スペクトル回帰の傾き | 地声=浅い(高次倍音リッチ)／裏声=急（低次に集中） | 実音で確認: 元-4.6 / 裏声模擬-14.2 / 地声模擬-3.5 → **主指標** |
| **H1–H2** (dB) | 第1倍音と第2倍音の振幅差 | 声門の開放率の指標。大=裏声寄り／小・負=地声寄り | 声門源由来の理論的相関として併用 |
| **フォルマント F1/F2/F3** | LPC（自己相関法, 根→共鳴周波数, 帯域幅でフィルタ） | 共鳴・母音・歌手フォルマント(2.8–3.4kHz)＝張り/通り | LPCで安定抽出（n≈1000フレーム） |
| ロールオフ÷f0（既存） | 既存 | 補助的な明るさ指標 | 既存維持 |

> フォルマント自体は主に「母音・共鳴」を表し、声区の直接指標ではない。本設計では
> **声区は傾斜＋H1-H2＋ロールオフの多数決**で判定し、**フォルマントは
> 「声の共鳴・張り（歌手フォルマント）」という別インサイト**として併用する。

## 4. 推定ロジック（多数決＋信頼度）
各「伸ばし区間」ごとに3つの票を集める（chest=+1 / head=-1 / neutral=0）:
- spectral_tilt: `>= -6`→+1 / `<= -11`→-1 / それ以外 0
- h1h2_db: `<= 2`→+1 / `>= 8`→-1 / それ以外 0
- rolloff_to_f0: `>= 6`→+1 / `< 4`→-1 / それ以外 0

`score = Σ票`。
- `score >= 2` → **chest**、`score <= -2` → **head**、それ以外 → **mix**
- **信頼度** = 票の一致度（|score|/有効票数）。有効票<2 や 区間数<2 は low。

セッション全体では区間ごとのラベルを集計し、最多ラベル＋信頼度を提示。

## 5. 出力（analyzer 結果への追加）
- 伸ばし区間 `sustained_segments[i]` に:
  `spectral_tilt_db_oct`, `h1h2_db`, `formant_f1_hz`, `formant_f2_hz`, `formant_f3_hz`,
  `register`(=voice_type を多数決で更新), `register_confidence`(high/med/low)
- 解析全体に:
  `formant_f1_hz`, `formant_f2_hz`（中央値）, `spectral_tilt_db_oct`（中央値）,
  `singers_formant_ratio`（2.8–3.4kHz帯のエネルギー比＝張り/通りの指標）

## 6. FB（声診断カード）への反映
- 「使っている声（推定）」: 多数決ラベル＋信頼度。**low なら「判定が難しい（短い/情報不足）」**と明示。
- 新ロウ「声の共鳴（フォルマント）」: F1/F2 と歌手フォルマントの有無から
  「前に通る・芯のある共鳴」/「こもり気味」を**目安**として提示（断定しない）。
- 「換声点（推定）」: 改善された register と信頼度を使い、信頼度が低い区間は除外。

## 7. 非機能・制約
- 追加計算は伸ばし区間のみ（全フレームLPCは重いので限定）。1録音あたり +数百ms 目安。
- 既存 `voice_type_estimate` キーは後方互換で残す（= 新ラベルを格納）。
- マイグレーション不要（解析結果は都度算出、DBスキーマ変更なし）。

## 8. 受け入れ基準
- AC-1: 伸ばし区間に F1/F2/F3・傾斜・H1-H2 が入る（Noneでない区間が過半）。
- AC-2: 裏声寄り（傾斜が急）な音源で head 方向、地声寄りで chest 方向に動く。
- AC-3: 情報不足（区間<2 / 票割れ）のとき信頼度 low で「判定が難しい」と出る。
- AC-4: 既存フローがエラーなく動作（短い録音・無声でもクラッシュしない）。
