# ウェルカムメール自動送信 テスト計画

- 文書番号: 87
- 作成日: 2026-08-01
- 作成: QAエンジニア
- 関連: docs/84（機能要件書 AC-01〜06）, docs/85（設計書 §10）, docs/86（文面・実送信手順）

## 1. スコープ
- `backend/app/services/mail_service.py`（単体）と `POST /api/v1/auth/register` フック（結合）の自動テスト。
- 対象外: Brevo への実送信（運用者がキー設定後に docs/86 §実送信の確認手順 で1回実施）、メールの受信箱到達性。

## 2. 対象機能要件
FR-01（登録時送信）/ FR-02（失敗隔離）/ FR-03（env制御）/ FR-04（文面・CTA）/ FR-05（ログ）

## 4. テスト環境
- in-memory SQLite ＋ FastAPI TestClient（既存 `tests/test_voice_type_anonymous.py` / `test_analysis_limit.py` のイディオム）。ネットワーク不要（requests をモック）。
- 実行: `cd backend && ./.venv/bin/python -m unittest tests.test_welcome_email -v`

## 5. 合格基準
- TC-01〜09 全パス、かつ既存テストスイート（backend/tests/）に回帰なし。
