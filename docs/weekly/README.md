## フォローの方針（アシスト型）

**自動フォローは実装も実行もしない**（X の自動化ルール違反＋凍結トリガーの筆頭）。
代わりに週次ルーティンが「手動フォロー候補」（検索クエリ＋選定基準）を出し、**フォロー操作は人間が手で1日5〜15人**だけ行う。フォロバ狙いの即アンフォロー（churn）はしない。リプ下書きと同じ「機械は下書き／実行は人間」の原則。
