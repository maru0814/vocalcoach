# ゼロ円集客プラン（ソラ先生 / 発声特化AIボイストレーナー）

広告費ゼロで、最初の100〜1000ユーザーを集めるための実行計画。本番稼働中・無料・Webアプリ。

## 0. 結論（先に要点）
- ゼロ円集客の本質は「**プロダクト自体に拡散の仕掛けを埋める**（シェアできる結果）」＋「**検索とSNSに価値あるコンテンツを置き続ける**」。
- 一人運用で効くのは2つに絞ること: **① シェアできる発声診断カード（要開発）** と **② Xで毎日1本の"発声の科学"＋無料診断フック**。
- 最大の武器: 「**自分の声を録音1回で診断**」「**地声/裏声をAIが聞き分ける**」という"やってみたくなる"体験。カラオケ採点文化のある日本ではスコア/診断は拡散しやすい。

## 1. ターゲット（ペルソナ一人）
**「独学カラオケ勢の23歳・カイト」**
- カラオケでうまく歌いたいが、ボイトレ教室（月1万円〜）は高い・恥ずかしい。
- YouTubeで練習法は見るが「自分の声が今どうなのか／何を直せばいいのか」が分からない。
- DAMの採点は気にする。X・YouTube・TikTokを毎日見る。

接触チャネル: X（ボイトレ・歌い手・カラオケ界隈）、YouTube、note/検索、Discord。

## 2. メッセージ
- **コア（一文）**: 録音1回で、あなたの"発声"をAIが診断。地声か裏声かの聞き分けから、声が前に出ない原因と直し方まで、無料で。
- 補足3つ:
  1. ボイトレ教室に行かなくても、自分の声の"今"が数値と言葉で分かる。
  2. アンザッツ理論・音声医学（声の芯CPP・声帯の閉じH1-H2）に基づく本格的な処方。
  3. 原曲リンクを貼れば、原曲と比べて音程・声区まで具体的にアドバイス。
- 誇大表現は禁止。「プロになれる」ではなく「自分の声の課題と次の一歩が分かる」。

## 3. チャネル優先順位（ゼロ円・ROI順）

### Tier 1（最優先：拡散ループとXの土台）
**① シェアできる発声診断カード【要開発・最大の梃子】**
- 診断結果を1枚の画像にして「Xでシェア／画像保存」ボタンを付ける。
  - 載せる: 総合スコア、声タイプ（例: ミックス寄り）、ソラ先生のひとこと総評、ロゴ＋URL。
  - OGP（リンク貼ると画像が出る）も整える。
- ハッシュタグ例: #ソラ先生診断 #声診断 #ボイトレ
- これがあると「声診断やってみた」投稿が自然発生 → 流入コスト0のループ。
- KPI: シェア率（診断完了者の何%がシェアしたか）目標≧10%、シェア経由の新規登録数。

**② X（旧Twitter）：毎日1本の"発声の科学"＋週1の無料診断フック**
- 1投稿＝1メカニズム（機構→原因→処方）。例:
  - 「"声が通らない"の正体は声帯の閉じ（H1-H2）。息が漏れると芯が出ない。ストロー発声で閉じを整えると、同じ息でも前に鳴る。」
  - 「地声で高音を押し上げると喉が締まる。原曲がミックスならアンザッツ4（軟口蓋に当てる）で声帯を後ろに伸ばす。」
- 週1で「あなたの声、地声?裏声?AIが無料で聞き分けます→URL」。
- フォロワー0からの最速手は"他人の悩みに即・具体回答"（リプ・引用RT）。ボイトレ/歌い手垢に価値提供で絡む。
- 目標(30日): 投稿30本、フォロワー0→300、プロフィールリンクのクリック累計≧500。

### Tier 2（複利・遅効：検索資産）
**③ note / ブログでSEO**
- docs/21（発声の科学）を検索意図に合わせ記事化。狙うクエリ例:
  - 「ミックスボイス 出し方」「地声 裏声 違い」「声 通らない 原因」「ボイトレ アプリ 無料」「自分の声 地声か裏声か 調べる」
- 各記事末に「無料で自分の声を診断する→」CTA。月4〜8本。
- KPI: 検索表示回数、記事→診断のCTR≧5%。（成果は2〜3ヶ月で立ち上がる前提）

**④ YouTube Shorts / TikTok（任意・伸びしろ大）**
- 「AIに自分の声を診断させてみた」「地声と裏声、AIは聞き分けられる?」の実演ショート。画面録画でOK。

### Tier 3（瞬発・関係作り）
**⑤ コミュニティで"答える"**: r/singing、ボイトレ/歌い手Discord、Yahoo!知恵袋の関連質問に科学的に回答し末尾でツール紹介（価値先行・スパム禁止）。
**⑥ ギフティング**: ボイトレ系YouTuber・歌い手 20〜50人に「無料ツール作ったので感想もらえたら」とDM。1人紹介すれば波及。お金は使わない。
**⑦ ローンチ告知**: 「アンザッツ理論×AIで発声診断できる無料ツール」の新規性でXスレッド＋note＋はてブ。

## 4. 最初の30日（一人運用の現実的な動き）
- **Week 0（仕込み）**: シェア画像機能を実装、OGP整備、Xアカウント開設＋プロフィール（固定ツイートに無料診断リンク）、note記事2本仕込み。
- **Week 1**: ローンチ告知（Xスレッド＋note公開）。毎日1豆知識投稿。知恵袋/Discordで合計3件回答。
- **Week 2**: 自分で「声タイプ診断やってみた」投稿＋シェア導線を検証。ボイトレ垢10人に価値提供で絡む。
- **Week 3**: note 2本追加（SEO狙い）。ギフティングDM 20人。
- **Week 4**: 数値で振り返り、効いた1〜2チャネルに集中。勝ち筋を太くする。

## 5. KPI（30日目標）
| 指標 | 目標 |
| --- | --- |
| 新規登録 | 100〜300 |
| 診断完了率（録音まで到達） | ≧60% |
| 結果シェア率 | ≧10% |
| X経由リンククリック（累計） | ≧500 |
| note→診断 CTR | ≧5% |
| 7日以内の再録音（リピート） | ≧20% |

## 6. 正直なリスク・前提
- **ゼロ円＝無料ではない**。最大コストは「時間と継続」。1日1〜2時間のX/コンテンツ運用が要る。
- 拡散の効きは**「シェアできる結果」に依存**。これが無いと口コミは起きない → まずここを作るのが最優先。
- SEOは遅効（2〜3ヶ月）。即効はX＋シェアループ。
- スパム的告知は逆効果。常に"価値先行"（先に役立つ→さりげなく誘導）。
