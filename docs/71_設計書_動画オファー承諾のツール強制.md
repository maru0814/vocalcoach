# 71. 設計書 — 動画オファー承諾時のツール強制（リンクが出ない事故の修正）

- 作成: 2026-07-17
- 役職: バックエンドエンジニア
- 関連: docs/44（ソラ先生ツール化）, docs/65（提案済み練習の文脈注入）, docs/66（会話モード）

## 1. 事象（本番で発生）

ソラ先生が「参考になる実演動画を出しましょうか？」と提案し、ユーザーが
「お願いします」「はい」「どれ？」と答えても、URL が一度も出ないまま
「こちらです。」を繰り返す。

## 2. 原因

1. ツール強制判定 `_wants_reference()`（`backend/app/coaching/llm.py`）は
   **今回のユーザー発言のキーワード**（動画・お手本・参考…）しか見ない。
   オファーへの承諾（「お願いします」「はい」「どれ？」）はどれにも該当せず
   `force_tool=False` になる。
2. 強制なし（AUTO）だと flash-lite は自発的に `find_reference_video` を
   呼ばない（既知の弱点。llm.py のコメントに明記）。URL をでっち上げた場合も
   最終ガード `_scrub_foreign_urls` がカタログ外 URL を削除するため、
   どちらに転んでも本文にリンクが残らない。
3. ツール化 OFF 時の確定経路（`handle_video_request`）は
   `coach_tools_enabled=True`（本番既定）ではスキップされ、救済が無い。
4. 追加要因: 話題写像 `TOPIC_KEYWORDS`（rule_engine.py）に
   「リップロール」等の**練習名そのもの**が無く、仮にツールが呼ばれても
   topic=リップロール では found=false になる。

## 3. 対応（決定論の網を1枚足す）

### 3-1. 承諾検出でツールを強制する（llm.py）

- `_accepts_video_offer(user_text, history)` を新設:
  - 直前のコーチ発言が動画オファー（既存 `_VIDEO_OFFER_RE`）または
    動画を出す約束（新設 `_VIDEO_PROMISE_RE`: 「動画をお出しします」
    「こちらが〜動画です」）にマッチし、かつその発言に URL が無い
  - 今回のユーザー発言が短い承諾・催促（お願いします/はい/ぜひ/見たい/
    どれ/ない 等。「いらない」「大丈夫」等の辞退は除外）
  - → True なら `generate_reply` で `force_tool=True`（mode=ANY）
- 承諾ターンは docs/66 の会話モード（短い一言＝雑談扱い）より優先し、
  「find_reference_video を呼び実URLを本文に載せる」指示を状況に注入する。
- 約束マッチも対象にすることで、**既に壊れた会話**（「こちらです。」の後の
  「どれ？」）からも次のターンで復帰できる。

### 3-2. 練習名を話題写像に追加（rule_engine.py）

`TOPIC_KEYWORDS` に、taxonomy の★練習（practices[0]）に実在動画がある
練習名を追加する:

| キーワード | task_id | ★練習の動画 |
| --- | --- | --- |
| リップロール | pitch_wobble | リップロールのやり方と練習法 |
| ストロー | breathy_closure | リップロール／ストローのやり方と練習法 |
| あくび | throat_tension | 喉がどんどん開くトレーニング |
| ハミング | weak_resonance | ミックスが掴める簡単ハミング練習法 |

## 4. 変えないこと

- URL の供給源はツール（taxonomy 実データ）のみ。LLM が URL を書く経路は
  引き続き `_scrub_foreign_urls` で遮断（捏造防止の設計は不変）。
- ツールが実URLを返したのに本文に無い場合の確定追記
  （`（参考動画 → URL）`）も従来どおり＝リンク到達の最終保証。

## 5. テスト

`backend/tests/test_conversational_fb.py` に追加:
- 承諾検出: オファー直後の「お願いします」「はい」「どれ？」→ True、
  オファー無し・辞退・直前ターンでURL渡し済み → False
- 壊れた会話からの復帰: 「こちらが〜動画です。」（URL無し）の後の「どれ？」→ True
- 話題写像: `find_reference_video("リップロール")` が found=true で
  カタログ実URLを返す（ストロー/あくび/ハミングも同様）
