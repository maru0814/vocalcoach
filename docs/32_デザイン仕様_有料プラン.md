## 3. 各画面仕様

### S-01 残回数バッジ
- 解析開始画面の上部に常時表示: 「今月の解析 のこり **7回**」（無料のみ。加入者には出さない）。
- のこり3回以下で文言追加: 「たくさん練習するなら → プレミアム」（テキストリンク→S-02）。
- 0回: 解析ボタンを無効化し、ボタン直下に S-02 を開くCTA「プレミアムで続ける」。

### S-02 アップグレードモーダル
- 見出し: 「もっと練習したいあなたへ 🎤」（上限到達時）/「録音をもっと深く知りたいあなたへ」（レポート/履歴経由）。
- 本文: 機能差分表（docs/31 §3 の5行をそのまま）＋ 価格「**月額 ¥500**（いつでも解約OK）」。
- CTA: プライマリ「プレミアムをはじめる」→ Checkout。セカンダリ「今はやめておく」→ 閉じる。
- 禁止: 偽の緊急性（「今だけ」等）・解約しづらい印象を与える文言。**「いつでも解約OK」を必ず明記**。
- 計測: 表示時に導線種別（limit / report / history）を付与してイベント送信。

### S-03 詳細添削ロックカード
- 解析結果画面のスコア下に配置。レポートの**見出しだけ**を薄く見せる（①どこで ②なにを最優先に ③7日間メニュー ④次回チェック）＋ 中央に鍵アイコン。
- CTA: 「プレミアムで添削を見る」→ S-02（種別=report）。
- 加入者には同位置に「詳細添削を見る」ボタン（生成済みなら「レポートを見る」）。

### S-04 履歴ロック行
- 履歴一覧の11件目以降を1つの集約行で表示: 「ほか N 件の録音はプレミアムで見られます」→ S-02（種別=history）。
- 個別行は出さない（タイトル等のメタ情報も見せない。期待だけ持たせて見せないのはストレスのため）。

### S-05 プラン管理（設定内）
- 現在のプラン表示: 「無料プラン」or「プレミアム（次回更新: M/D）」。
- 無料: 「プレミアムをはじめる」→ S-02。加入者: 「お支払い・解約の管理」→ Customer Portal（外部）。
- 解約済み・期間残あり: 「プレミアム（M/D まで利用できます）」。

### S-06 詳細添削レポート画面
- パス: `/recordings/[id]/report`。
- 構成は4セクション固定・縦1カラム。①箇所別の指摘は「タイムスタンプ（タップで該当位置から再生）＋事象＋推定原因」のカード。②最優先ポイントは1枚だけ大きく。③7日間メニューはDay1〜7のチェックリスト（チェック状態はlocalStorage）。④次回チェックポイントは3項目の箇条書き。
- 生成中: スケルトン＋「ソラ先生が聴き込んでいます…（最大3分）」。失敗時: 「時間をおいて再試行」ボタン。

### S-07 決済戻り
- 成功 `/billing/success`: 「ようこそプレミアムへ 🎉」＋「さっそく詳細添削を見る」（直前の録音へ）/「ホームへ」。webhook未反映の間は「反映中…」スピナー（最大60秒ポーリング）。
- キャンセル `/billing/cancel`: 責めない文言「またいつでもどうぞ」＋元の画面へ戻るリンク。

## 4. 共通ルール

- 価格表記は税込「¥500/月」。S-02/S-05/LPで統一。
- 鍵アイコン＋淡色オーバーレイをロックの共通表現とする（モーダル乱発しない。モーダルはユーザー操作起点のみ）。
- 文言はすべてソラ先生口調（です・ます、絵文字は1画面1〜2個まで）。
- アクセシビリティ: ロック状態はアイコンだけでなくテキストでも伝える。モーダルはEscで閉じる・フォーカストラップ。
