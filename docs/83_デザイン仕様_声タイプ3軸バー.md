# 声タイプ3軸バー デザイン仕様

- 作成日: 2026-07-29（ユーザー指示: 3軸をバーで図示して表示したい）
- 対象: 診断結果カード（測定位置）＋タイプ別記事ページ（タイプ固定位置）の両方を**同一部品**で表示

## 1. ユーザーゴール

- 診断直後: 「自分の声が3つの軸のどこにあるか」を、文字を読まずに一目で掴む
- 記事ページ: 「このタイプは3軸のどこか」を掴んでから本文を読み、8タイプを見比べたときに違いが分かる
- 両者を同じ物差しで並べることで、「自分の位置」と「タイプの位置」がそのまま比較できる

## 2. 3軸の定義（正本: `backend/app/coaching/voice_coach.py` の判定式）

| 軸キー | 左ラベル | 右ラベル | 内部値 | 判定に使う指標 |
| --- | --- | --- | --- | --- |
| `register` | 地声寄り | 裏声寄り | chest / head | H1-H2（声門開放率）＋声区推定 |
| `power` | パワフル | ソフト | power / airy | CPP・HNR・シンガーズフォルマント比 |
| `color` | 明るめ | 暗め | clear / deep | スペクトル傾斜＋シンガーズフォルマント比 |

- **ラベルは上記に統一する**（2026-07-29 ユーザー指定）。旧ラベル「地声成分が多め」「エアリー（息まじり）」「クリア（明るい）」は廃止し、`_AXIS_JP` も本表に合わせる
- 8タイプは3軸の全組み合わせ（2×2×2）。したがって記事ページ側の位置は**タイプが決まれば一意**

| タイプ | register | power | color |
| --- | --- | --- | --- |
| rock（ロック） | 地声寄り | パワフル | 明るめ |
| groovy（ソウル） | 地声寄り | パワフル | 暗め |
| pop（ポップ） | 地声寄り | ソフト | 明るめ |
| mysterious（ミステリアス） | 地声寄り | ソフト | 暗め |
| crystal（クリスタル） | 裏声寄り | パワフル | 明るめ |
| dramatic（ドラマティック） | 裏声寄り | パワフル | 暗め |
| whisper（スウィート） | 裏声寄り | ソフト | 明るめ |
| moody（セクシー） | 裏声寄り | ソフト | 暗め |

## 3. 画面ごとの仕様

### SCR-VT1: 診断結果カード（`VoiceTypeResult.tsx`）
- **目的**: 自分の測定位置を示す
- **変更**: 現在のピル3つ（「やや地声成分が多め」等のタグ）を**バー3本に置き換える**
- **位置**: `desc`（タイプ説明文）の直下、参考アーティストの上
- **マーカー位置**: 実測スコアから算出（§4）。境界に近い（`near=true`）軸は自然に中央寄りに来る
- **地色**: タイプ別グラデーションの上。白系トーン（`tone="onColor"`）
- **シェア画像**: このカードは画像保存・シェアの対象なので、CSSのみで描画し画像化に耐えること（外部フォント・SVG依存を作らない）

### SCR-VT2: タイプ別記事ページ（`VoiceTypeProfileArticle.tsx`）
- **目的**: そのタイプの座標を、本文を読む前に渡す
- **位置**: 導入（lede）カードの内側・本文の下に hairline で区切って配置。目次より前
- **マーカー位置**: タイプ固定（§4 の 0.18 / 0.82）。**極の端に貼り付けない**——診断は断定しない方針（docs/62 §5）に合わせ、少し内側に置く
- **地色**: 白カードの上（`tone="surface"`）
- **キャプション**: 「このタイプの位置」＋「※ 声の傾向からの推定です（優劣ではありません）」

### 状態
| 状態 | 扱い |
| --- | --- |
| loading | 結果カード自体が出る前なので専用表示なし（既存のローディングを流用） |
| empty | `axes_pos` が無い（解析不足で `classify_voice_type` が None）→ **バーを描画しない**。ピル同様、無い時は何も出さない |
| error | 一部の軸だけ欠損はしない（3軸まとめて算出）。欠損時は empty と同じ扱い |
| success | バー3本＋キャプション |

## 4. 位置の算出

内部スコア `s`（+ が左ラベル側、- が右ラベル側）から 0〜1 の位置へ写す。0＝左ラベルの極、1＝右ラベルの極、0.5＝どちらとも言えない。

```
pos = 0.5 - clamp(s, -1.5, +1.5) / 3      # s=+1.5 → 0.0 / s=0 → 0.5 / s=-1.5 → 1.0
描画時はさらに 0.06〜0.94 に収める（マーカーが端で切れるのを防ぐ）
```

- タイプ固定値（記事ページ）: 左側の極 = **0.18** / 右側の極 = **0.82**
- 中央（0.5）を基準線とし、**中央からマーカーまでを塗る偏差バー**にする。極からの塗りにしない——「地声成分が何%」という量の誤読を防ぐため（測っているのは偏りであって量ではない）

## 5. デザイントークン

| 要素 | surface（白地・記事） | onColor（色地・結果カード） |
| --- | --- | --- |
| ラベル文字 | `text-slate-500` / 11px / bold | `text-white/80` / 10px / bold |
| トラック | `bg-slate-200` / h-1.5 / rounded-full | `bg-white/25` |
| 中央基準線 | `bg-slate-300` / w-px / h-3 | `bg-white/40` |
| 偏差の塗り | `bg-brand-500` / h-1.5 | `bg-white/70` |
| マーカー | `bg-brand-600` + `ring-2 ring-white` / 12px 円 | `bg-white` + `ring-2 ring-white/50` |
| 行間 | 行ごと `gap-2`、3行を `gap-3` | 同じ |
| キャプション | `text-[10px] text-slate-400` | `text-[9px] text-white/60` |

- 装飾色は増やさない（docs/61 v2「引き算の規律」＝アクション色は brand 単系統）。タイプ色は地色のグラデが担当しているので、バー側で色を足さない

## 6. アクセシビリティ要件

- バー1本＝`role="img"` ＋ `aria-label="<左ラベル>から<右ラベル>のうち、<近い側>寄り"`（例: 「地声寄りから裏声寄りのうち、地声寄り」）。境界に近い軸は「やや」を付ける
- 目や色に依存しないよう、`aria-label` だけで内容が完結すること（バーは視覚的な補助）
- 装飾要素（トラック・基準線）は `aria-hidden`
- コントラスト: onColor のラベルは白80%以上（グラデ最明部 amber-500 上でも 4.5:1 を確保できる濃度をQAで確認）
- 動きは付けない（`prefers-reduced-motion` 対応不要な静的表示）

## 7. docs/62 §4 との関係（重要）

docs/62 §4 には「**3軸の判定式を本文に載せない**」「軸ラベルの断定的併記を撤去」（2026-07-12 ユーザー指示）というルールがある。本仕様はこれを**覆さない**:

- 維持: 記事の**散文**に「A地声×Bエアリー×Aクリア」式の表記や軸ラベルの併記を書かない
- 追加: 軸の位置は**視覚部品（バー）として別枠で**示す。散文と混ざらないので、読み物としての質を落とさずに情報を渡せる
- docs/62 §4 にこの追補を1行記載する
