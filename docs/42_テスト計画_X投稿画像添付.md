# X自動投稿 ブランド画像添付 テスト計画

対象: `scripts/sns_autopost/`（X自動投稿ツール）への「全投稿へ縦4:5ブランド画像を自動添付」機能。
実装: `images.py`（新規）/ `generate_and_post.py` / `approval_queue.py` / `webhook.py` / `line_client.py` ほか。
作成: QAエンジニア（2026-06-29）

## 1. スコープ
- 画像生成（AI背景 + Pillowフォールバック + 日本語見出し焼き込み）
- 生成画像のXメディア添付投稿（v1.1 `media/upload` → v2 `tweets`）
- 承認フロー（生成→キュー→LINE→webhook）で画像が最終投稿に乗ること
- 各スイッチ（`SNS_IMAGE` / `SNS_IMAGE_AI` / `SNS_FONT_PATH` / `SNS_IMAGE_MODEL`）の挙動
- 既存フロー（本文生成・2部構成・予算ガード）の非破壊（回帰）
- 非スコープ: X APIプラン自体の可否、Imagenの画質評価、LINE UIの見た目

## 2. 対象機能要件（FR）
- FR-01: 全投稿（昼/夜・全ピラー）に縦4:5（1080×1350）画像を1枚添付する
- FR-02: 背景をGemini(Imagen)で生成する（`SNS_IMAGE_AI=1`・有効キー時）
- FR-03: AI生成が失敗/キー無/不正モデル/認証エラーのとき Pillowグラデ背景に自動フォールバックし、必ず画像を出す
- FR-04: 日本語見出しはAIに焼かせず Pillow で後描画する（崩れ・誤字を出さない）。見出しはcuratedテンプレ文から起こす
- FR-05: 生成画像をXに media/upload → tweetに `media_ids` で添付する。アップロード失敗時は文字だけで投稿継続
- FR-06: 承認フロー（LINE→webhook）で、承認時に下書きの画像が最終投稿に添付される
- FR-07: `SNS_IMAGE=0` で従来どおり画像なし投稿（後方互換）
- FR-08: CJKフォント未検出時もクラッシュせず、文字なし画像を出す（警告ログ）
- FR-09: 既存の本文生成・2部構成・予算ガード・キュー/承認が壊れない
