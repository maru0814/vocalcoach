# 会話型FB デザイン仕様

対象機能: [36_機能要件書_会話型FBリニューアル.md](36_機能要件書_会話型FBリニューアル.md)

## 1. ユーザーゴール
録音を送ったあと、採点表ではなく「人間のコーチとチャットしている」感覚で、短く・自然に・自分の苦手に寄り添ったやりとりができる。

## 2. 画面一覧
| ID | 画面名 | パス | 目的 |
| --- | --- | --- | --- |
| SCR-01 | コーチ会話 | `/coach/[sessionId]` | 録音・テキストでソラ先生と会話する（本機能の主画面） |

新規画面は作らない。既存のチャット画面の**メッセージの出し方**を変える。

## 3. 会話デザインの中核ルール

### 3.1 吹き出しの量
- **練習提案なしのターン → coach返答はテキスト1吹き出し**。現状の「カード4連発」を廃止。
- **練習提案ありのターン → 2吹き出し**に分ける（①感想・気づき → ②練習法＋必要なら動画リンク1行）。人間のコーチが「まず一言 → そして具体的なやり方」と続けて話す自然なテンポに合わせる。
- 1吹き出しは **2〜4文・目安120字以内**。テキスト経路（既存チャット）と同一。
- 3吹き出し以上には分割しない。

### 3.2 トーン（ソラ先生）
- 一人称「わたし」。やわらかい敬体。絵文字は1メッセージ0〜2個。
- 話し言葉。**見出し（#）・箇条書き記号（- / *）・点数・◎○△×・指標の表は使わない**。
- 専門用語を出すときだけ、直後に一言で噛み砕く（例:「声帯の閉じ（息の効率）」）。多用しない。
- 「採点」ではなく「気づき＋一緒に直す提案」のトーン。

### 3.3 Before / After（このトーンに揃える）

ユーザー: 「サビの高いとこ、声がひっくり返っちゃう」

✗ 旧（カード＋長文。廃止する）:
```
【総合 72点】■音程: 高音域で不安定 ■リズム: 概ね良好 ■表現:…
■改善ポイント 1.腹式呼吸 2.リップロール 3.…
（＋採点カード＋基礎練カード＋チップ）
```

◯ 新（このくらいの温度・長さ）:
```
あー、サビでひっくり返るやつですね。たぶん地声で押し上げようとして
喉が詰まってる感じかも。一回、力を抜いて裏声寄りで同じところを
歌ってみてもらえますか？どうなるか聞いてみたいです🎤
```

### 3.4 練習法の出し方（苦手検知ターンのみ）
- 検知された主課題が1つあるときだけ、会話の流れで**1つ**渡す。
- **2吹き出し構成**（①感想・気づき → ②練習法）:
```
① あー、サビの高いとこ、地声で押し上げ気味かもしれません。
   喉が少し詰まって聞こえます🎤

② こういうときは「ネイネイ」って鼻に響かせながら1音ずつ上げてみると、
   力まずに高さを稼げますよ。やってみて録ってもらえたら、変わったか一緒に見ますね😊
   （参考にこの動画わかりやすいです → https://…）
```
- **出さないのが普通**。課題が無い録音・通常の質問では練習法を足さない。
- 一度すすめた練習名は会話が続く間そのまま。「できない/合わない」と言われた時だけ1つ切り替える。

### 3.5 良い録音のとき
- 無理に「もっと良くする点」をひねり出さない。素直に褒めて終えてよい。
```
今の高音、すごく楽に出せていますね。響きも前に通っていて良い状態です✨
このまま別の箇所も聞かせてください🎶
```

## 4. メッセージ状態（4種）
| 状態 | 表示 | コピー例 |
| --- | --- | --- |
| loading | 既存のタイピングインジケータを流用 | （ソラ先生が入力中…） |
| empty（録音前） | 既存の初回メッセージ | 「まずは練習したいところを歌って録音を送ってくださいね🎤」 |
| error（解析失敗） | textで一言。表は出さない | 「うまく聞き取れませんでした🙏 もう少し長めに歌って、もう一度送ってください」 |
| success（FB） | text 1〜2吹き出し（本仕様） | 3.3 / 3.4 参照 |

## 5. 旧カードのフォールバック表示（過去ログ互換）
過去セッションに残る `feedback` / `practice` / `judge` / `progress` / `diagnosis` 型メッセージは、新規には生成しないが**履歴では壊さず表示**する。

- **方針**: 旧カードUI（円グラフ・◎○△×・表）はレンダリングしない。代わりに、控えめなプレーンテキストの吹き出しにフォールバックする。
- **見た目**: 通常のcoachテキスト吹き出しと同じスタイル。淡色で「以前の診断結果」と分かる短い要約のみ。
- **コピー例**:
  - feedback → 「（以前の診断メモ）このとき見ていたのは『高音の張り上げ』でした。」
  - practice → 「（以前すすめた練習）ネイネイ・スケール」
  - progress → 「（以前の比較メモ）前回より伸ばしの安定が良くなっていました。」
- payload から安全に拾える最小情報（課題ラベル・練習名）だけを使い、点数・◎○△×は表示しない。情報が無ければ「（以前の診断結果）」のみ。

## 6. デザイントークン
新規トークンは追加しない。既存の coach テキスト吹き出し（`rounded-2xl rounded-bl-md bg-white ... ring-slate-100`）をそのまま使う。フォールバック吹き出しは本文を `text-slate-400` 程度の淡色にして「過去の参考」と分かるようにする。

## 7. アクセシビリティ要件
- 会話文のみになるため、色だけに依存した情報（◎○△×の色分け）が消え、スクリーンリーダー可読性は向上する。
- リンク（参考動画）は `target="_blank" rel="noreferrer"` を維持し、リンクテキストに動画の主旨が分かる語を含める（「参考動画を見る」単独にしない）。

## 8. フロントエンドへの申し送り
- `MessageBubble` の `isCard` 分岐を、旧型は §5 のフォールバックへ、新規FBは text として描画するよう変更。
- 新規メッセージは type=`text` のみで成立させる（backendがカード payload を送らなくなる前提）。
- `ActionChips`（次にやることチップ）の扱いは要確認: 会話を阻害しない範囲で残すかをアーキテクトと調整（本仕様では必須としない）。
