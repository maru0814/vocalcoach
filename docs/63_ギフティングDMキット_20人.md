# ギフティングDMキット（送付20人・返信3を目標）

> 根拠: docs/62（CEO決定・集客全振り30日）／docs/23 §3 Tier 3 ⑥
> 原則: 価値先行・お金は使わない・スパムにしない（1日3〜5通まで）・送信は必ず人間

## 1. 送付先リストの作り方（選定基準）

**探す場所**: X検索・YouTube検索「ボイトレ」「歌ってみた」「ミックスボイス 解説」「発声 練習」

**選定基準（すべて満たす人だけリストに入れる）**
| 基準 | 目安 | 理由 |
| --- | --- | --- |
| 規模 | フォロワー/登録者 1,000〜50,000 | 大手は返信率が低い。マイクロ層は試してくれる率が高く、紹介の波及も十分 |
| 活動 | 直近30日以内に投稿あり | 休眠アカウントに送っても無駄弾 |
| 内容 | 発声・練習法・歌ってみたを自分の言葉で語っている | ツールの価値を理解し、感想を言語化できる人 |
| 接点 | DM開放 or リプで会話している | 送れない人をリストに入れない |
| 除外 | 他のボイトレアプリの案件・アンバサダー | 競合利益相反。断られるだけでなく心証を悪くする |

**リスト管理**: スプレッドシートに「名前／URL／規模／ジャンル／送付日／返信／結果」の7列。
20人を一気に送らず、**1日3〜5通×4〜5日**に分ける（同文面の一斉送信はスパム判定・凍結リスク）。

## 2. DM文面（3パターン・コピペ後に◯◯を必ず個別化）

**共通ルール**
- 冒頭1行は必ず相手の実際の投稿・動画に触れる（ここが空だと定型営業と見なされ終わり）
- 「案件ではない・お金は発生しない・宣伝義務もない」を明言する
- 返信がなくても追撃しない（1回きり）

## 3. 返信が来たときの対応

- **好意的**: 御礼＋「結果画面はそのままシェアできます」だけ伝える。シェアの催促はしない。
- **指摘・辛口**: 全て記録して `qa-engineer` / `vocal-trainer` に回す（外部専門家のFBは最高の品質資産）。
- **無反応**: 追撃しない。リストに「×」を付けて終わり。
