## 0. 何が新しくなったか（告知のネタ元）

## 1. ターゲット（1人に絞る・docs/24 と同じ）
- 独学で歌を練習している20〜30代。カラオケで高音が苦しい／音痴か不安／教室は気後れ。
- MBTI・性格診断でシェアして友達と比べる層。「自分の声を“言葉で”知りたい」欲求に効く。

### 4-2. タイプ別スポットライト（1日1本・水/土「図鑑」枠）
既存の `scripts/sns_autopost/themes.py` の診断導線（`self_type`/`voice_type`）は、この規律で自動生成される：
**「似てる歌手の正体当て」フックで止め → 自己リプに8タイプ早見**。カタログ始まり・URL本文混入はしない。
手動で1タイプを立てる場合のテンプレ（URLなし・実名必須）:
```
{絵文字}{英名} タイプの声、思い当たる人。

{artists_for(id) の実名2人}に“声質が近い”と言われがちなタイプ。
{あるある を1つ、共感トリガーとして}

自分がどのタイプかは、15秒歌えばAIが判定。
```
→ 自己リプは 4-1 と同じ `cheatsheet_reply()`。導線はプロフィール固定。
実名の正本は `themes.ARTISTS_BY_ID`（でっち上げ禁止・`voice_coach.py` と同時更新）。
あるあるの素材（各タイプ）:
- 🔥Rock（LiSA・Mrs. GREEN APPLE）: 「原曲キーを下げるの、実力じゃなく“気持ち的に”悔しい」

- 🌒Mysterious（宇多田ヒカル・米津玄師）: 「“え、歌うんだ”から株が急上昇する」
- 💎Crystal（西野カナ・藤原聡(髭男)）: 「その日の満足度が“最高音の出来”で決まる」
- 🎭Dramatic（Aimer・星野源）: 「歌い終わったあと、自分でも一拍黙る」
