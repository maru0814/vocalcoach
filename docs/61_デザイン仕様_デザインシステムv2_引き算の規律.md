# デザインシステム v2「引き算の規律」 デザイン仕様

- 作成: 2026-07-05（UXデザイナー）
- 目的: docs/55「ソラのステージ」の世界観を維持したまま、実行品質をデカコーンToC水準へ引き上げる
- 根拠: ティアダウン監査（本ドキュメント §2）。Duolingo / Spotify / Headspace の規律分析に基づく

## 1. 診断の要約

個人開発感の正体は装飾の不足ではなく**語彙の過剰**。実測: ボタン36種・アクセント色6系統・グラデ45箇所・余白59種・文字16サイズ・角丸12種・チャット外絵文字12ファイル。v2 は新しい装飾を足さず、**語彙を制限する**。

## 3. v2 トークン（規則＝許可リスト方式）

### 3-1. カラー役割制

| 役割 | 色 | 許可される用途 |
| --- | --- | --- |
| アクション | brand-600（単色） | ボタン・リンク・選択状態。**UIのアクセントはこの1系統だけ** |
| 世界観 | night-800/900/950 ＋ bg-stage | 暗面セクションのみ |
| 本文 | slate-800 / 500 / 400 | テキスト階層 |
| 成功 | emerald-600系 | 成功トースト・達成表示**のみ** |
| エラー | rose-600系 | エラー表示**のみ** |
| 禁止 | fuchsia / cyan / amber / pink の装飾使用 | イラスト・図鑑アート内のみ許可。UIクロームでは使わない |

- **グラデーションは1画面1箇所まで**（原則ヒーローの `bg-stage` の空だけ）。`bg-brand-gradient` のボタン・チップ・数字・テキストへの使用を全廃
- neon.* トークンは StageDecor（星・音符）と glow 影のみに縮退

### 3-2. タイポスケール（5段固定）

| 段 | 指定 | 書体 | 用途 |
| --- | --- | --- | --- |
| display | text-5xl〜7xl / font-black / tracking-tight / leading-[1.1] | Zen Maru Gothic | ヒーローh1のみ |
| heading | text-3xl〜4xl / font-black / tracking-tight | Zen Maru Gothic | セクションh2 |
| title | text-lg〜xl / font-bold | Zen Maru Gothic | カード見出し・h3 |
| body | text-sm〜base / font-normal / leading-relaxed | **Noto Sans JP** | 本文・説明文 |
| caption | text-xs / font-medium | Noto Sans JP | 注記・メタ情報 |

- **まる文字（Zen Maru）は見出しとソラ先生の台詞だけ**。本文を Noto Sans JP に分離して「かわいいが読みやすい」を作る（Headspace型）
- 恣意値（text-[9px]〜[13px]）は caption に統合。font-bold の本文使用をやめ、強調は色（slate-800）で行う

### 3-3. スペーシング・角丸

- 余白は 8pt グリッド: `1,2,3,4,6,8,10,12,16,20,24`（Tailwind単位）のみ。セクション間は `mt-20` 統一→見せ場の前だけ `mt-24`
- 角丸3段: `rounded-lg`(8px)=入力・小要素 / `rounded-2xl`(16px)=カード / `rounded-full`=ピル・アバター。`rounded-3xl`/`[2rem]`系はセクション面（`rounded-[2rem]`に統一）だけ

### 3-4. ボタン（Duolingo型・唯一の型）

`src/components/ui/Button.tsx` に集約。**LP/アプリ内のCTAはすべてこれを使う（独自クラスでのボタン作成を禁止）**

| variant | 見た目 | 用途 |
| --- | --- | --- |
| primary | bg-brand-600 単色＋**下辺影 shadow-[0_4px_0_#5b21b6]**、hover で明度+、active で translate-y-[3px]＋影1px（沈む） | 主CTA（1画面1つ） |
| secondary | bg-white＋border＋下辺影 slate | 副CTA |
| ghost | 透明＋hover で bg-brand-50 | 三次的操作 |

- 5状態必須: default / hover / active(沈む) / focus-visible(ring-2 ring-brand-400 ring-offset-2) / disabled(opacity-40・影なし)
- 暗面上の primary は同型のまま（brand-600 は night 上でコントラスト4.5:1以上）

### 3-5. アイコン

- IconChip を**単色化**（bg-brand-600 + 白ライン）。グラデ地を廃止
- アイコンセットを12種に拡充し、**チャット吹き出しの会話文以外の絵文字を全廃**（対象12ファイル）

### 3-6. キャラ＝ポーズライブラリ（新設 `/brand/poses/`）

| ポーズ | ファイル | 用途 |
| --- | --- | --- |
| 歌う | singing.png | LPヒーロー・ブランドの顔 |
| 教える | explain.png | FB解説・機能紹介・チュートリアル |
| 応援(👍) | cheer.png | 空状態・励まし |
| よろこび | clap.png | 成功・上達・診断完了 |
| 考える | thinking.png | ローディング・解析中 |
| お辞儀 | bow.png | 完了・お礼・ログアウト |

- 実装: `CoachAvatar` に `pose` prop を追加（省略時は従来の顔アイコン）。**同一画面に同じポーズを2回出さない**
- 生成手段: 既存 `scripts/sns_autopost/assets/characters/sora` と同一パイプライン（Gemini画像モデル＋既存2枚を参照画像に）。追加生成時も同手順でタッチを固定する
- 拡張（声タイプ別シーン絵）: 声タイプ図鑑のセクション見出しには、共通ポーズの代わりに**タイプ専用のシーン絵**（`/brand/poses/<typeId>/*.jpg`・640px正方・背景つき）を置ける。`CoachAvatar` の `poseSrc` prop で指定し、背景つきのため透過ポーズと違い**円形バッジ（rounded-full＋ring）で表示**する。第1弾はクリスタルタイプ5枚（voice/weakness/speaking/personality/songs。aruaru は共通 clap を継続）、第2弾はロックタイプ6枚（全セクション）、第3弾はグルーヴィータイプ6枚（全セクション）、第4弾はポップタイプ5枚（voice/weakness/speaking/personality/aruaru。songs は共通 cheer を継続・画像制作中）

### 3-7. 製品を見せる（機能紹介の作り直し）

- 「グラデ地＋アイコン」パネルを廃止し、**実物のチャットUIと同じ見た目のミニ製品モック**（ProductSnippet: 端末風フレーム＋実データ調の会話2〜3吹き出し）に差し替える
- 内容は機能ごとに実FBの文体（docs/42準拠）で書く。誇張数値・偽スコアは載せない

### 3-8. モーション

- 環境ループ（twinkle/noteFloat/floaty）は暗面のみ・現状維持（reduced-motion対応済み）
- 追加するのは**行動への反応**だけ: ボタン押下の沈み込み、カードhoverの浮き（hover:-translate-y-0.5＋shadow-card-2、統一済み）
- 新規アニメライブラリは導入しない
