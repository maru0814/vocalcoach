# 35. デザイン課題と改善方針（デザイナー × PdM 議論）

> ソラ先生（AIボーカルコーチ Webアプリ）のプロダクト本体のデザイン課題を、UXデザイナーと
> PdMが実装コード（`frontend/src/app/`）と要件ドキュメント（docs/01,09,10,11,12,16,31）を
> 突き合わせて洗い出し、議論してまとめたもの。対象は **LP→声診断→登録→録音→レポート→
> コーチング** の体験全体。

- 作成: 2026-06-29
- 参加: UXデザイナー / PdM
- 関連: docs/09, 10, 11, 12, 16, 31, 32

---

## 0. 結論サマリ（先に読む）

体験の **入口（声診断）と情報設計（主役の不在）** に最大の課題がある。LPとコーチUIは
作り込まれているが、(1)価値を見せる前に登録ゲートが立ち、(2)同じ「録音→FB」が複数画面に
散らかり、(3)無料→有料の転換導線が“磨かれた主役画面”に存在しない。優先順位は
**入口KPI（登録率・診断完了率）→ 情報設計 → 課金転換 → 状態網羅の土台**。

---

## 1. 完全に一致した最重要課題（異論なし）

### 課題1【高】声診断が「アハ体験の前に登録の壁」を立てている
- 該当: `frontend/src/app/voice-type/page.tsx`（`auth==="out"` で録音UIを出さず登録ゲート, L155-175 付近）
- 問題: 声診断は docs/11 で “集客の主役・US-01の入口”。なのに**価値（自分の声タイプ）を
  1秒も見せる前にメール登録を要求**。LP（`page.tsx`）は「15秒歌うだけ」「そのままシェア」と
  約束しているのに、最初の行動が録音でなくフォーム入力になっている。
- 要件の抜け: 「未登録でも1回は診断結果を見せ、シェア/保存時に登録」という**トライアル動線が
  docs/11 にも docs/31 にも未定義**。
- 改善方向: 未登録で1回診断を完走 → 結果カードをぼかして提示 → **シェア/保存の瞬間に登録**を差す
  “アハ→登録”順へ。
- KPI: 登録率 / 診断完了率（最上流）

### 課題2【高】旧 `recordings` 画面がデザインシステムから断絶
- 該当: `frontend/src/app/recordings/page.tsx`, `recordings/new/page.tsx`
- 問題: ここだけ `bg-blue-600` / `text-red-600` / 小角丸の生Tailwindで、ブランドの
  `glass` / `rounded-3xl` / `brand-gradient`（coach/voice-type）と別アプリに見える。
  SiteHeaderも無い。さらに同じ「録音→FB」が **coach と recordings に二重存在**。
- 改善方向: ブランドトークンへ統一。録音→FBの導線を一本化（課題6の主役確定とセット）。
- KPI: 録音率 / 継続率

### 課題3【高】無料→有料の転換導線が、主役画面に存在しない
- 該当: 課金UI（docs/31の上限表示・アップグレード面・詳細ロック）は実装上 `recordings/*` と
  `api.ts` のみ。`coach` / `voice-type` には課金・上限・価値訴求がゼロ。
  レポートの `forbidden`（要課金）状態（`recordings/[id]/report/page.tsx` L127-133）は
  **アップグレード導線も戻る導線も無い行き止まり**。
- 問題: 価値の山（FB直後・成長実感 = US-02）に導線が出ず、捨てられている旧画面にだけ出る。
- 要件の抜け: FR-05の「3導線」を**どの画面に置くか**の画面マッピングが docs/31 で未指定。
- 改善方向: 「制限の通告」でなく「次にできること」として、感情のピーク（FB直後 / 成長実感 /
  上限到達）に主役画面でアップグレード面を出す。
- KPI: 課金転換

### 課題4【中〜高】状態網羅（loading/empty/error/success）が画面で不均一
- 該当: `recordings/new/page.tsx`（**success無し**＝無言遷移、エラーが「アップロードに失敗
  しました」と曖昧）、`recordings/page.tsx`（empty/loading無し、error は赤テキスト一行、
  再試行UIなし＝docs/01 NFR-05 未実装）。一方 `voice-type` / `coach` は4状態が丁寧（良い手本）。
- 根因: **各機能要件書のACが success 中心**で、loading/empty/error の受け入れ基準がほぼ無い
  （docs/11・docs/10）。だから実装が画面ごとにバラつく。
- 改善方向: ACに状態網羅条項を追加。エラー文言は原因＋次の手を具体化
  （例「音声ファイルが大きすぎます（最大N MB）」）。
- KPI: 診断完了率 / 録音率

## 2. 視点が分かれた／補完し合った点

| 論点 | UXデザイナー | PdM | 落とし所 |
| --- | --- | --- | --- |
| 本丸はどこか | 画面単位のUX破綻（コピー・状態・モバイル操作） | 情報設計（主役不在・3分岐の散らかり） | 両方。IAを直さないと画面修正がモグラ叩きになる |
| 主役の扱い | （言及薄） | coach を主役に据え、旧 recordings を畳む/吸収せよ | PdMのIA判断を先に → デザイナーが統合フローを描く |
| モバイル操作 | `Composer.tsx` L143-152：送信が ⌘/Shift+Enter 前提で**スマホ破綻**。録音上限も画面間で不一致（coach 1:00 / 声診断 20秒） | （言及薄） | デザイナー主導で即修正可（軽い） |
| 誠実さの見せ方 | （言及薄） | 反ハルシネーション（docs/12,16）で「—」が多発。**“なぜ—か・どう埋めるか”のデザインが無い**と「壊れてる/薄い」に見える | 要件化が必要（PdM→デザイナー） |
| 要件と実装の乖離 | — | coach は今も `PhaseStepper`（A-E `PHASE_LABEL`, `coach/page.tsx` L14-19）。docs/10 FR-05は「強制ステッパー廃止→軽いラベル」を要求 | 実装が要件に未追従。散らかり感の一因 |

## 3. 統合した改善ロードマップ（優先順）

1. **【入口】声診断を未登録で1回完走**（結果ぼかし→シェア/保存で登録）。登録率・診断完了率に直接効く。
2. **【IA】主役を coach に確定し、旧 recordings を畳む/吸収**＋ブランド統一。「1つの中心＋補助」に整理。
3. **【転換】FB直後・上限到達の“瞬間”にアップグレード面**を主役画面へ（「次にできること」の見せ方）。
4. **【土台】状態網羅をACに条項化**（loading/empty/error/success＋具体エラー文言）＋モバイル送信/録音上限の修正＋PhaseStepperの要件追従。

> 順序の根拠（PdM）: 1→2が入口KPI、課金(3)は母数が乗ってから効く。
> 制約（デザイナー）: 2のIAが決まらないと 1も3も“置き場所”が決まらない。**まず主役を確定**する。

## 4. 仕様で決めるべきオープン論点（PdMが裁定）

1. **声診断の認証ゲートの位置**: 「未ログインで1回診断→結果ぼかして登録」か「登録必須」か。
   現状コードは“登録必須”で確定済み。これは意図か事故かを確認し、トライアル動線を docs/11 に追記する。
2. **詳細レポートの課金境界と見せ方**: `PREMIUM_REQUIRED` 時に何を見せ何を隠すか（ティザー表示か
   全閉じか）、アップグレード導線の位置。docs/31 に画面マッピングを追記する。
3. **生成3分の待ち体験**: レポート生成（最大3分）・声解析（10秒）を、その場待ちにするか
   バックグラウンド＋完了通知にするか。スマホで3分張り付きは非現実的。
4. **主役の確定**: coach / voice-type / recordings の3入口を「1つの中心＋補助」へ。recordings を
   畳むか coach に吸収するかを決める。

## 5. 付随で見つかった実装の綻び（バックログ候補）

- `coach/[sessionId]/page.tsx` / `coach/page.tsx`: error 文言が最終的に「エラーが発生しました」
  「うまく処理できませんでした」に落ち、原因も次の手も無い（docs designer SKILL の原則違反）。
- `coach/page.tsx`: ヘッダーの「ログアウト」が遷移（`/login`）のみで、トークンを消す処理が無い（誤誘導）。
- `Composer.tsx`: placeholder「⌘+Enter で送信」がスマホでは意味不明。録音バーの上限がハードコードで
  声診断側と不一致。
- coach の `PhaseStepper`（A-E）が docs/10 の「強制ステッパー廃止」と乖離。
