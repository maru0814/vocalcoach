- 作成: 2026-07-17（QAエンジニア）

## 1. スコープ
PWA化のインストール可能性・オフライン挙動・Web Push（購読/配信）・状態網羅を検証する。
- 対象: manifest/SW/インストール導線/オフライン表示/通知トグル/配信スクリプト/購読API。
- 対象外: 解析ロジック・FB品質（docs/42 不変。変更なし＝回帰確認のみ）。ネイティブアプリ（docs/72でLater）。

## 2. 対象機能要件
FR-01 manifest / FR-02 インストール導線 / FR-03 Service Worker / FR-04 Web Push購読 / FR-05 配信。

## 3. テスト観点
正常系 / 異常系 / 境界値 / 状態遷移（許諾6状態・オンオフ）/ ブラウザ差分（Chrome・iOS Safari・非対応）/ セキュリティ（他ユーザー購読の不可操作）/ プログレッシブ・エンハンスメント（非対応で機能デグレなし）。

## 4. テスト環境
- 本番相当 HTTPS（PWA/PushはHTTPS必須）。ローカルは `localhost`（SW許可オリジン）。
- 端末: Android Chrome / PC Chrome / iOS Safari 16.4+（ホーム画面追加済み）/ 非対応（購読不可ブラウザ）。
- backend: `VAPID_*` 設定済み環境。未設定時の挙動も確認（配信スキップ）。
