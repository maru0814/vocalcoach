## 0. なぜ方針転換するか（レビュー要約）

現状の「純正TTS＋汎用Pexels実写＋字幕でTips量産」は、平均1,000〜2,000再生で埋没する見込み。理由：
1. **Tipsが飽和**（正しいが新しくない＝既視感で2秒離脱）
2. **B-rollが内容と無関係**（`broll.py` の機械マッピング＝「ストック量産アカ」とバレる）
3. **声ジャンルでAI音声を使う自己矛盾**（純正TTSは没個性）
4. **見て満足→診断に飛ばない**（Tipsは保存されて終わり、事業KPIに効かない）

→ ボイトレで実際に伸びる勝ち筋は **「ビフォーアフター実演」と「AI診断の実演」**。声がどう変わるか/AIが何を当てるかを“見世物”にする。これは顔出し不要のまま **ソラ先生にしか作れない**。

副仮説 H2: 高音の Before/After 実演が、Tips解説より勝つ。

## 3. 計測設計（ここが甘いと検証にならない）

### 3-1. オン・プラットフォーム指標（TikTokアナリティクスから各動画）
- **3秒残存率 / 平均視聴時間 / 完了率**（＝視聴維持率。最重要）
- いいね / **コメント** / **保存** / シェア
- **プロフィール表示数**（動画→プロフ遷移の代理指標）

### 3-2. ファネル指標（事業KPI）
- TikTokは動画内リンク不可。**bioに UTM付きリンク**を1本だけ置く:
  `https://sora-vocal-ai.duckdns.org/voice-type?utm_source=tiktok&utm_campaign=t36`
- LP/診断側のアクセス解析で **診断開始数** を日次で見る。
- どの動画が遷移を生んだか切り分けるため、**アームごとに“合言葉”をCTAに変える**:
  - A=「コメントで“高音”」 / B=「コメントで“タイプ”」 / C=「コメントで“どっち”」
  - コメントの合言葉数＋プロフ表示数で、アーム別の関心度を近似する。

### 3-3. 記録シート（毎日転記）
| 日付 | アーム | 動画 | 再生 | 3秒残存% | 平均視聴s | 完了% | コメント | 保存 | プロフ表示 | 合言葉数 |

## 5. 判定ルール（1週間後）

- **B または C が、A を「平均視聴時間 AND プロフ表示率」で上回ったら仮説採用。**
  - B が勝ち → パイプラインを**診断デモ型**に改修（broll.py の汎用Pexels依存をやめ、診断画面録画を素材化）。
  - C が勝ち → **Before/After 実音型**に改修（TTS解説をやめ、実音2本を軸に）。
- A が勝つ or 全アーム横ばい（全部3秒残存<20%）→ ニッチ/フックの前提から見直し（題材を変える）。
- いずれも **再生数は結果指標。視聴維持率とプロフ遷移で判断**（再生に一喜一憂しない）。
