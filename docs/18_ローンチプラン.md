# Launch Plan｜AIボーカルトレーナー ソラ先生

## ターゲット
- **一次ターゲット（ペルソナ）**: 独学で歌を練習している初〜中級者（20〜30代）。
  カラオケ／弾き語り／歌い手活動を上達したいが、ボイトレ教室は高い・恥ずかしい・続かない。
- **接触チャネル**:
  - X（旧Twitter）: #歌うまになりたい #ボイトレ #カラオケ練習 #弾き語り 界隈
  - note: 「独学ボイトレの記録」「AIに歌を添削させてみた」系の体験記事
  - Discord / コミュニティ: 歌い手・カラオケ・DTM/弾き語りサーバー
  - YouTube/TikTokショート: 「AIに歌を採点＆添削させたら的確すぎた」リアクション動画

## メッセージ
- **コアメッセージ（一文）**:
  「録って送るだけ。AIが“どこを・どう直すか”を秒数つきで返します。」
- **補足メッセージ（3つ）**:
  1. 「下手」が「サビ後半で息が切れている」に変わる——直す場所が分かる。
  2. 原曲を入れれば、音を外していないか・リズムのズレを聴き比べて見られる。
  3. 盛らない正直なFB。直し方（基礎練＋実演動画）までセットで返す。

## 差別化（競合との違い・正直に）
- 採点アプリの「点数だけ」と違い、**言葉で“どこを・どう直すか”**＋**基礎練の方法**まで返す。
- **原曲とのAI聴き比べ**で音程の正確さ・リズムを実測（多くの無料採点には無い）。
- **誇張しない**設計。「プロ並み」とは言わず、推定は推定と明示——逆に信頼を訴求材料にする。

## タイムライン（T=ローンチ日）
- **T-7日｜ティザー**: 「独学の歌、“どこを直すか”分からない問題を解決するもの作ってます」+ 解析画面のGIF。
- **T-3日｜詳細告知**: 機能3つを1枚図解で。原曲聴き比べ・声診断・基礎練動画を見せる。ウェイトリスト/URL予告。
- **T-1日｜カウントダウン**: 自分の歌をソラ先生に添削させたBefore/Afterの短尺デモ。
- **T 0｜本告知**: 公開URL＋「無料で歌を見てもらう」。30〜60秒の使い方デモ動画を固定ポスト化。
- **T+1〜2日｜体験の拡散**: 初期ユーザーのFBスクショ（許可制）/ 自分の上達ログを公開。
- **T+3日｜使用感共有**: 「3日で“伸ばしの揺れ”が減った」など定量の小さな勝ちを共有。
- **T+7日｜改善版告知**: 初週フィードバックで直した点を告知（“声を聞いて改善する運営”を見せる）。

## コンテンツ企画（タイトル案）
- note: 「AIボイストレーナーに“同じ曲”を7日間添削させたら、何が変わったか」
- X連投: 「無料の歌採点と何が違うの？を3枚で説明」
- ショート動画: 「AIに音痴か判定させたら、直し方まで教えてくれた」

## 成功指標（KPI・初週）
- 7日以内に **登録 50人**
- **FB送信（録音）100件**
- **2回目の録音に戻った人 30%**（＝価値が刺さった指標）
- X告知ポストの **保存/リンククリック 200**
- 定性: 「どこを直すか分かった」という声を **10件**収集（次の改善材料）

## ローンチ前チェック（マーケ目線）
- [ ] 公開URLが安定（本番デプロイ済み・HTTPS）
- [ ] 未ログインでもLPで価値が分かる（Hero〜機能3つ）
- [ ] 最初の1録音までの導線が3タップ以内
- [ ] FBの「正直さ」が伝わる文言になっている（盛らない＝信頼）
- [ ] 問い合わせ/フィードバック窓口（フォーム or DM）

## リスクと対応
- **解析が刺さらない録音（無音/短尺/非歌唱）**: 既に録り直し誘導を実装済み（QA対応済）。
- **過度な期待（プロ判定を期待）**: LP・FAQで「目安・推定」を明示し、原曲比較で精度を上げられると案内。
- **初速が出ない**: ショート動画のリアクション系を1本仕込み、コミュニティへ手動で初期接触。
