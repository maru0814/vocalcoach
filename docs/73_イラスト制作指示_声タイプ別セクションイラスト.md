# 声タイプ別セクションイラスト 制作指示書（48枚）

関連: docs/72（声タイプ別テーマ）/ docs/62（プロフィール記事雛形）/ docs/61 §3-6（ポーズ規律）
実装: `frontend/src/components/voice/SectionArt.tsx` — `/voice-types/sections/{typeId}/{sectionId}.png` を置くとその画像が表示され、無い間はソラ先生のポーズ画像（docs/72 §5-2 のタイプ別割当）に自動フォールバックする。**画像を置くだけで反映、コード変更不要。**

## 1. 目的
記事セクション見出し横のソラ先生を「全タイプ共通のポーズ使い回し」から、**各タイプ×各セクションの本文内容を演じる専用イラスト**に差し替え、タイプごとのページの個性を完成させる。

## 2. 共通仕様
- ファイル: `frontend/public/voice-types/sections/{typeId}/{sectionId}.png`
  - typeId: rock / groovy / pop / mysterious / crystal / dramatic / whisper / moody
  - sectionId: voice(魅力) / weakness(苦手) / speaking(話し声) / personality(性格) / aruaru(あるある) / songs(輝く曲)
- 640×640px・透過背景PNG（既存 `/brand/poses/*.png` と同一仕様。表示は72px正方・object-contain）
- 画風: 既存のチビ調ソラ先生（紫髪グラデ・大きな瞳・丸みのある線）。`/brand/poses/` と `/voice-types/{id}.jpg` を画風リファレンスにする
- 主役はソラ先生。衣装・小道具・色味をタイプの世界観（docs/72 §4-1）に寄せてよいが、キャラの同一性（紫髪・顔立ち）は崩さない
- 小さく表示されるため、要素は1〜2個まで。文字は入れない

## 3-2. 画像生成AI用マスタープロンプト（Gemini等）
毎回、①既存ポーズ絵（`frontend/public/brand/poses/singing.png` と `explain.png`）を参照画像として添付し、②以下のマスタープロンプトの【カット】行を §3 の該当カット指示に差し替えて、1カットずつ生成する。

> 添付画像のキャラクター「ソラ先生」（紫グラデーションの髪・大きな瞳・チビ調デフォルメ・丸みのある太めの輪郭線・フラットなアニメ塗り）を、添付とまったく同じ画風・同じ顔立ちで描いてください。
> 条件: 正方形1枚／キャラクター1人のワンカット／背景は完全な無地の白／画像内に文字・ロゴを入れない／小物は1〜2個まで／全身または膝上。
> 【カット】（ここに §3 のカット指示を貼る。衣装・照明はタイプの世界観に寄せてよいが、髪色と顔立ちは変えない）

生成後の白背景の透過化・640pxへのリサイズ・`sections/{typeId}/{sectionId}.png` への配置はエンジニア側で行うため、生成画像はそのまま納品でよい。

## 4. 制作・搬入手順
1. 上記指示で画像生成（既存ポーズ絵と同モデル/同スタイル推奨）→ 640×640 透過PNGに整形
2. `frontend/public/voice-types/sections/{typeId}/` に配置（部分納品OK。置いた分から自動で切替わる）
3. 全部そろったら、フォールバック用のタイプ別ポーズ割当（docs/72 §5-2）は保険としてそのまま残す
