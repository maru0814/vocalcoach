# 有料プラン（サブスクリプション） 機能要件書

> PdM作成 v2（2026-06-12）。v1は単発¥500の詳細FBだったが、CEO（まる）の決定により**サブスク型に変更**。
> docs/20（黒字化プラン §3 プラン案・Phase 2 実装項目）に準拠。単発課金はやらない。

## 1. 概要

- **一言説明**: 月額サブスク「ソラ先生 プレミアム」を導入する。無料プランに利用上限を設け、上限超過と高付加価値機能（詳細添削レポート等）を有料化する。
- **解決する課題**:
  - ユーザー側: 「点数だけでは練習に落とせない」→ 詳細添削＋無制限の練習サイクルを提供
  - 事業側: 支払い意思の検証と、継続収益（MRR）の確立。docs/20 の試算では**有料2〜4人で黒字**。

## 2. 想定ユーザー / ユースケース

- **ペルソナ**: 20〜40代のカラオケ・歌好き。週1回以上練習し、録音解析を繰り返し使う。月数百円なら趣味に払える。
- **主要ユースケース**:
  1. 無料ユーザーが月の解析上限に達し、「続けるならプレミアム」導線から加入する。
  2. 無料FBを見たユーザーが「詳細添削レポート」を見たくて加入する。
  3. 加入者が毎週録音→解析→詳細レポート→練習のループを回す。
  4. 加入者がカスタマーポータルから自分で解約する。

## 3. プラン定義（docs/20 プラン案を初期値として採用）

| 機能 | 無料 | プレミアム **¥500/月**（初期検証価格） |
| --- | --- | --- |
| 4軸スコア・基礎練・声タイプ診断 | ◯ | ◯ |
| 録音解析 | **月10回** | 無制限 |
| 詳細添削レポート（下記FR-04） | × | ◯（解析ごとに生成可） |
| 原曲アップロード比較 | 体験1回 | ◯ |
| 履歴保存 | 直近10件 | 無制限 |

- 価格は env で変更可能にする（検証後 ¥980 への改定は CEO 判断・このdoc改訂で管理）。
- 発音アドバイス（Gemini音声・従量コスト）は本MVPでは**両プランとも対象外**（コスト変動が読めないため。Phase 3で再検討）。

## 4. スコープ

### 4.1 対象（やること）
- 無料プランの利用上限（解析 月10回・履歴 直近10件・原曲比較 体験1回）の計測とゲート
- Stripe サブスク決済（Checkout subscription mode）・解約（Customer Portal）・状態同期（webhook）
- 詳細添削レポート（加入者のみ・解析ごと）
- 上限到達時・有料機能接触時のアップグレード導線
- 転換率の計測

### 4.2 対象外（やらないこと）— MVP線引き
- 単発課金・回数券・年額プラン・複数価格帯
- 人間（プロトレーナー）による添削
- 日割り・返金の自動化（問い合わせベースで手動）
- 発音アドバイス（Gemini音声）の提供
- Claude Code 版（skill）への課金導入
- 既存無料ユーザーの履歴削除（上限超過分は「非表示」にとどめ、データは消さない）

## 5. ユーザーストーリー

- **US-01**: ヘビーに練習するユーザーとして、月10回を超えても解析を使いたい。なぜなら週2〜3回の練習サイクルを止めたくないから。
- **US-02**: 加入者として、録音ごとに「どこで・何が・なぜ」悪いかの詳細添削が欲しい。なぜなら点数だけでは練習方法に落とせないから。
- **US-03**: 加入者として、いつでも自分で解約したい。なぜなら解約に問い合わせが必要なサービスは信頼できないから。
- **US-04**: 運営者として、上限到達→加入の転換率を計測したい。なぜなら上限値（月10回）と価格の調整判断に使うから。

## 6. 機能要件

### FR-01: 利用上限（無料プラン）
- **概要**: 無料ユーザーの録音解析を月10回に制限する。
- **詳細仕様**:
  - カウント単位: 暦月（月初リセット・JST）。解析が**完了**した時点で1カウント（失敗・エラーは数えない）。
  - 残回数を解析画面に常時表示（例: 「今月あと3回」）。
  - 上限到達後の解析実行はブロックし、アップグレード導線（FR-05）を表示。
  - 履歴は直近10件のみ表示（11件目以降は非表示。削除しない。加入すると全件復活）。
- **例外**: 既加入者はカウント対象外。月跨ぎ中の解析はリクエスト受付時点の月に算入。

### FR-02: サブスク決済（Stripe）
- **概要**: ¥500/月のサブスク。カード決済。
- **詳細仕様**:
  - `POST /api/v1/billing/checkout` が Checkout Session（`mode=subscription`）を生成。`metadata`/`client_reference_id` に `user_id`。
  - Webhook `POST /api/v1/billing/webhook` で `checkout.session.completed` / `customer.subscription.updated` / `customer.subscription.deleted` / `invoice.payment_failed` を処理し、`subscriptions` テーブル（`user_id, stripe_customer_id, stripe_subscription_id, status, current_period_end`）を同期。署名検証必須。
  - ユーザーのプラン判定はDBの `status in (active, trialing)` かつ `current_period_end > now` で行う（リクエスト毎にStripeへ問い合わせない）。
- **例外**: 支払い失敗→Stripeの自動リトライに任せ、`past_due` の間は無料プラン扱いに降格。二重加入はチェックアウト作成時に拒否。

### FR-03: 解約（Customer Portal）
- **概要**: 設定画面の「プラン管理」から Stripe Customer Portal へ遷移し、自分で解約できる。
- **詳細仕様**: `POST /api/v1/billing/portal` がPortal Session URLを返す。解約後も `current_period_end` までは有料機能を使える（即時打ち切りしない）。

### FR-04: 詳細添削レポート（加入者特典）
- **概要**: 加入者は解析ごとに詳細添削レポートを生成・閲覧できる。
- **詳細仕様**: レポートは4セクション固定:
  1. 箇所別の指摘（最大5箇所。時間帯＋事象＋推定原因）
  2. 最優先の改善ポイント1つ
  3. 7日間練習メニュー（1日10分・具体的手順）
  4. 次回録音時のチェックポイント（3つ以内）
  - 解析結果画面の「詳細添削を見る」押下で生成（オンデマンド。録音ごとに1回生成し保存・再生成しない）。
  - docs/12（反ハルシネーション）に従い、解析データに根拠のない断定をしない。
  - 非加入者には同ボタンをロック表示（FR-05の導線）。
- **例外**: 生成失敗→自動リトライ2回→失敗時は「時間をおいて再試行」表示（課金は月額のため返金は発生しない）。

### FR-05: アップグレード導線
- **概要**: 無料ユーザーが価値を感じた瞬間に加入導線を出す。
- **詳細仕様**: 表示箇所は3つ: ①上限到達モーダル ②詳細添削ボタンのロック表示 ③履歴11件目以降のロック表示。いずれも「プレミアム ¥500/月」と機能差分の表を表示→Checkoutへ。
- **例外**: 加入者には一切表示しない。

### FR-06: 計測
- **概要**: ①各導線の表示数 ②押下数 ③Checkout開始数 ④加入完了数 ⑤解約数 を記録。導線別（上限到達/詳細添削/履歴）に集計可能にする。

## 7. 非機能要件

- **性能**: プラン判定はDB参照のみで行い、解析リクエストに +50ms 以上のオーバーヘッドを加えない。詳細レポートは生成開始から3分以内に閲覧可能。
- **セキュリティ**: Webhook署名検証必須。価格・プランIDはサーバ側定義。レポート・履歴は本人のみアクセス可。
- **コスト**: 月額固定費の新規追加なし（Stripeは従量手数料のみ ~3.6% → ¥500あたり実質粗利 ~¥480。LLM生成は加入者の解析回数に比例するがテキストのみで1回数円以内）。
- **保守性**: 上限値（月10回・履歴10件）と価格は env / 設定値で変更可能。
- **UX**: 上限・ロックの文言は「制限の通告」ではなく「できることの案内」のトーン（ソラ先生人格）。

## 8. 受け入れ基準

- **AC-01**: 無料ユーザーの11回目の解析がブロックされ、アップグレードモーダルが出る（10回目までは正常完了）。
- **AC-02**: 月が変わると無料ユーザーの解析カウントが0に戻る。
- **AC-03**: テストカードで加入完了→詳細添削ボタンが解放され、4セクション揃ったレポートが3分以内に表示される。
- **AC-04**: Customer Portalから解約→`current_period_end` までは有料機能が使え、期末以降は無料プランに戻る（履歴11件目以降が再ロック）。
- **AC-05**: 支払い失敗（`past_due`）のユーザーは無料プラン扱いになる。
- **AC-06**: Webhook署名が不正なリクエストは拒否される。
- **AC-07**: 加入済みユーザーが再度Checkoutを開けない（二重課金が発生しない）。
- **AC-08**: 非加入者が加入者用レポートAPIを直接叩くと 403。
- **AC-09**: 導線別の表示→押下→加入の件数が集計できる。

## 9. 前提・制約

- Stripe アカウント開設は人間（まる）が行う（本人確認が必要）。
- 公開前に「特定商取引法に基づく表記」ページが必要（販売者情報・価格・解約条件・提供時期）。サブスクは**解約方法の明記が法的に必須**（改正特商法のサブスク規制）。
- 既存ユーザーは全員無料プランとして扱う（遡及的な制限はリリース月から適用）。
- 価格 ¥500/月 は検証用初期値。docs/20 の想定レンジは ¥500〜980。

## 10. 未決事項 / 要確認

- **Q1**: 特商法表記の記載内容（個人名公開の扱い）→ まる確認。
