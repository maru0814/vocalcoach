# 実写B-roll キャッシュ（自動生成）

`broll.py` が Pexels から取得した縦型の実写素材を、ffmpegで **1080x1920にカバークロップ＋軽い暗化**
して `<video_id>.mp4` として焼く場所。本番の合成はこの焼き済みクリップを読むだけ＝軽い。

- 中身（`*.mp4` / `raw/`）は **Git管理外**（DL物・容量のため）。このREADMEだけ管理されます。
- 使うには `.env` に `PEXELS_API_KEY=`（無料・https://www.pexels.com/api/ ）と、OSに `ffmpeg` が必要。
- キーが無い/取得に失敗した場合は、動画は従来の背景（焼き込みモーション or 静止グラデ）にフォールバックします。
- 一度焼いた素材はキャッシュされ、次回以降は再ダウンロードしません。消せば作り直します。
