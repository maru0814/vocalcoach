# BGM（ロイヤリティフリー音源）の置き場

ここに音楽ファイルを1つ置くと、動画に**自動でBGMが乗ります**（小音量0.10・尺に合わせてループ）。

## 使い方
1. ロイヤリティフリー / 商用利用OK のBGMを1曲ダウンロードする。
2. このフォルダ（`assets/bgm/`）に置く。拡張子は `.mp3 / .m4a / .wav / .ogg / .aac`。
3. 次回の生成から自動で鳴る（`video_assembler._resolve_bgm` が先頭1ファイルを拾う）。

複数置いた場合はファイル名順で先頭が使われます。曲を変えたいときは入れ替えるだけ。

## どこで入手する？（無料・商用OK）
- **YouTube オーディオ ライブラリ**（要Googleアカウント。著作権表示不要のものを選ぶ）
- **Pixabay Music** … https://pixabay.com/music/ （登録不要・商用OK）
- **Uppbeat** … 無料枠あり（クレジット表記が必要な場合あり）
- TikTok に手動投稿するなら、アプリ内の**商用楽曲ライブラリ / 流行り音源**を使うのが一番伸びる
  （※流行り音源はAPIからは付けられないため、流行り音源狙いの回だけ手動投稿が現実解）。

## 注意
- このフォルダの中身（音源ファイル）は **Git管理外**（`.gitignore` 済み）。リポジトリには入りません。
- 権利的にグレーな音源（市販曲のリップ等）は使わない。BANやサウンド差し替えの原因になります。
