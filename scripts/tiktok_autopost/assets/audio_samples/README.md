# 音声サンプルプール（clip_recorder.py の入力）

clip_recorder.py がアプリに自動送信する「歌声サンプル」をここに置く。
4タグ × 2〜3本 = **最低8本** 用意すると demo_clips の多様性が出る。

## ファイル命名規則
`{tag}_{連番}.wav` または `.mp3`。先頭の `tag` が demo_clips のファイル名に引き継がれる。

| tag | 内容 | 録るとき意識すること |
| --- | --- | --- |
| `diagnose` | 声タイプ診断の全体フロー | しっかり歌い切る（15〜20秒） |
| `register` | 地声↔ミックス↔裏声の切り替わりが分かる歌い方 | 低音から高音まで動く曲のサビ |
| `pitch` | あえて少しだけ音を外して送る | ちょっとズレた状態を診断させる |
| `similar` | 「似た歌手が返ってくる」を見せる | 特定の歌手に寄せて歌う |

例:
```
diagnose_01.wav  diagnose_02.wav
register_01.wav
pitch_01.wav
similar_01.wav   similar_02.wav
```

## 録り方（スマホでOK）
1. ボイスメモアプリで 15〜25 秒録音（サビをメインに）。
2. WAV または MP3 で書き出し、ここに置く。
3. `python clip_recorder.py` を実行すると全ファイルを順番に処理。

> 音声ファイル本体は `.gitignore` で Git 管理外（容量のため）。
> このREADMEとファイル名の規則だけ管理する。
