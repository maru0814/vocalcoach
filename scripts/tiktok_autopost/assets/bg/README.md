# 焼き込みモーション背景の置き場

ここに**動く背景の動画**を1つ置くと、生成される動画の背景が“動いてる状態”になります
（`video_assembler._motion_bg` がこのフォルダの先頭ファイルを自動検出）。

## 作り方（一度だけ）
親フォルダで次を1回実行するだけ。ffmpegで動くグラデ背景を `motion.mp4` として焼きます。
```bash
cd scripts/tiktok_autopost
./make_motion_bg.sh
```
- 動き（ドリフト＋ゆっくりズーム）は**事前に焼き込む**ので、毎日の動画生成は軽いまま。
- 既定は35秒・ティール配色。配色を変えたいときは `make_motion_bg.sh` の `C0/C1/C2` を編集して再実行。
- このフォルダが空でも動きます（その場合は静止グラデ背景にフォールバック）。

## 自分で用意してもOK
ロイヤリティフリーの縦型(9:16)ループ動画をここに置けば、それが背景になります
（拡張子 `.mp4 / .mov / .webm / .mkv`。動画の最大尺34秒以上が望ましい）。

## 注意
- 背景の動画ファイルは **Git管理外**（`.gitignore` 済み）。このREADMEだけ管理されます。
- 派手すぎる背景は字幕の可読性を下げます。暗め・低コントラストの動きが安全です。
