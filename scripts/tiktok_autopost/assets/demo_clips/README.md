# 検証型の画面録画プール（demo_clips）

検証型(`demo`)動画に被せる「アプリ操作の画面録画」を、ここに `.mp4` で置く。
一度 20〜30本録っておけば、あとは自動で使い回される（docs/34：手動作業は“一度だけ”）。

## ファイル命名
`{tag}_任意名.mp4`。先頭の `tag` で `themes.DEMO_SCENARIOS` のシナリオに紐づく。

| tag | 何を録るか |
| --- | --- |
| `diagnose` | 録音→声タイプ診断の結果が出るまで |
| `register` | 地声/ミックス/裏声の判定が表示される画面 |
| `pitch` | 音程のズレ・外した区間が可視化される画面 |
| `similar` | 似た声質の歌手が提示される結果カード |

例: `diagnose_01.mp4`, `register_slow.mp4`

## 録り方（縦9:16・10〜15秒）
1. スマホ/PCのブラウザで本番アプリを操作。
2. OSの画面録画でアプリ操作を撮る（音は不要。ナレーションは自動で別途付く）。
3. 縦長(1080x1920目安)で、結果が出る“気持ちいい瞬間”を含める。

> mp4本体はGit管理外（`.gitignore`）。容量のためリポジトリには置かない。
